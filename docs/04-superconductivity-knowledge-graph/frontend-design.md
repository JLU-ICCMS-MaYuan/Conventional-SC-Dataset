# 04 超导发展知识图谱前端设计

## 页面定位

负责把论文、材料、物性参数和结构化记录组织为可查询关系层，为 RAG 和未来图谱页面提供基础。

## 页面入口

- 当前没有独立知识图谱页面。
- 未来页面展示材料节点、论文节点、物性边、年份和压力关系。
- 未完成的图谱探索能力需要标注「有待建设」。

## 交互原则

- 已落地能力正常展示，未落地能力统一使用「有待建设」标识。
- 页面只展示当前用户能理解和操作的内容，不把后端内部状态暴露成复杂表单。
- 表格、图表和上传控件保持现有 SC-Wiki 视觉风格，优先复用已有组件和样式。

## 状态设计

- 加载中：显示明确的状态文案。
- 空结果：说明当前没有可展示数据。
- 失败：展示可读错误，不吞掉后端错误原因。
- 未登录：提示登录后再使用上传、自定义或管理能力。

## 验收标准

- KG 数值查询与 RAG 回答一致。
- 空关系有明确提示。
- 审核状态过滤正确。
