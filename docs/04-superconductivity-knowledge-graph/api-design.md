# 04 超导发展知识图谱API 设计

## API 定位

本模块 API 服务于「超导发展知识图谱」能力，要求字段语义稳定、来源可追溯、错误信息可读。

## 当前或规划接口

- 当前通过 `POST /api/rag/chat` 间接调用 KG。
- 未来新增 `/api/knowledge-graph/material/{formula}` 查询材料局部图。
- 未来新增 `/api/knowledge-graph/search` 支持按元素、Tc、压强和年份筛选。

## 请求设计原则

- 请求参数使用明确字段名，避免前端自行拼接复杂业务规则。
- 涉及用户能力的接口必须校验登录状态和角色权限。
- 涉及审核、导出、批量操作的接口必须返回可验收的结果摘要。

## 响应设计原则

- 响应保留实体 ID、显示名称、来源、审核状态和错误信息。
- 面向表格或图表的接口返回前端可直接消费的扁平结构。
- 兼容旧接口时，新字段只增不破坏旧字段。

## 错误处理

- 400：请求字段缺失或格式错误。
- 401：未登录。
- 403：权限不足。
- 404：目标数据不存在。
- 409：数据冲突，需要人工确认。

## 验收标准

- KG 数值查询与 RAG 回答一致。
- 空关系有明确提示。
- 审核状态过滤正确。
