# 06 AI 辅助 Tc 估算后端设计

## 服务定位

负责基于结构文件和 PDOS 文件即时估算含氢体系 Tc，不是已审核数据库入口。

## 核心后端设计

- 当前由 `backend/api/tc_predict.py` 解析结构与 PDOS 并即时计算。
- 未来增加预测任务表，保存用户、输入摘要、模型版本、预测结果和失败信息。
- 预测结果默认不进入公开图表，必须经过审核。

## 数据模型

当前预测不入库。未来 `tc_prediction_jobs` 记录用户、模型版本、输入摘要、结果、状态、错误信息和创建时间。

## 权限与审核

- 普通用户只能提交或查看自己有权限访问的数据。
- 管理员负责审核、维护和批量操作。
- 涉及公开展示的数据必须保留审核状态和来源信息。

## 风险控制

- 数据库结构变更必须通过单独 migration 方案评审。
- 批量写入和批量审核需要 dry-run 或影响范围汇总。
- 任何未来规划能力不能伪装为当前已落地能力。

## 验收标准

- 缺少 H 原子能给出错误。
- 缺少 PDOS_H 能给出错误。
- 未审核预测不进入公开数据库。
