# 06 AI 辅助 Tc 估算当前规划

## 总体定位

负责基于结构文件和 PDOS 文件即时估算含氢体系 Tc，不是已审核数据库入口。

## 当前状态

已落地但实验性。

## 核心建设内容

### 前端

- `/tc-pre` 页面负责上传结构文件和 PDOS 文件。
- 结果区展示 predicted Tc、特征值和错误原因。
- 预测历史、模型版本和提交审核入口标注「有待建设」。

### 后端

- 当前由 `backend/api/tc_predict.py` 解析结构与 PDOS 并即时计算。
- 未来增加预测任务表，保存用户、输入摘要、模型版本、预测结果和失败信息。
- 预测结果默认不进入公开图表，必须经过审核。

### API

- `POST /api/tc-predict/`：当前即时预测接口。
- 未来新增预测任务创建接口、历史查询接口和提交审核接口。
- 响应需保留 `predicted_tc`、`f2_value`、`dos_h_ratio` 等解释字段。

## 数据模型与数据流

当前预测不入库。未来 `tc_prediction_jobs` 记录用户、模型版本、输入摘要、结果、状态、错误信息和创建时间。

## 验收标准

- 缺少 H 原子能给出错误。
- 缺少 PDOS_H 能给出错误。
- 未审核预测不进入公开数据库。
