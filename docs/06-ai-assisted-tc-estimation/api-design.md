# 06 AI 辅助 Tc 估算API 设计

## API 定位

本模块 API 服务于「AI 辅助 Tc 估算」能力，要求字段语义稳定、来源可追溯、错误信息可读。

## 当前或规划接口

- `POST /api/tc-predict/`：当前即时预测接口。
- 未来新增预测任务创建接口、历史查询接口和提交审核接口。
- 响应需保留 `predicted_tc`、`f2_value`、`dos_h_ratio` 等解释字段。

## 请求设计原则

- 请求参数使用明确字段名，避免前端自行拼接复杂业务规则。
- 涉及用户能力的接口必须校验登录状态和角色权限。
- 涉及审核、导出、批量操作的接口必须返回可验收的结果摘要。

## 响应设计原则

- 响应保留实体 ID、显示名称、来源、审核状态和错误信息。
- 面向表格或图表的接口返回前端可直接消费的扁平结构。
- 兼容旧接口时，新字段只增不破坏旧字段。

## 错误处理

- 400：请求字段缺失或格式错误。
- 401：未登录。
- 403：权限不足。
- 404：目标数据不存在。
- 409：数据冲突，需要人工确认。

## 验收标准

- 缺少 H 原子能给出错误。
- 缺少 PDOS_H 能给出错误。
- 未审核预测不进入公开数据库。
