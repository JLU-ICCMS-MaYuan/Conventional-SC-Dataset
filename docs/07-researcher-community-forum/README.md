# 07 研究者社区与图表论坛当前规划

## 总体定位

负责研究者身份、贡献可见性、社区图表和未来论坛互动。

## 当前状态

社区基础部分落地，论坛未落地。

## 核心建设内容

### 前端

- 首页图表区域或未来 Research Community 页面右上角标注「有待建设」。
- Tc 图表与 Tc-pressure 图表桌面端同行并排，移动端上下排列。
- Tc 图表在 77K 和 300K 添加横向虚线，并在区间内显示蓝到红渐变背景。
- 注册用户可删除个人图表点、添加数据库已有点、导出图片和数据表。

### 后端

- 默认图表继续由 `superconductor_records` 和图表规则生成。
- 用户自定义图表保存为个人配置，不影响全站默认图表。
- 删除点表示从个人图表隐藏，不删除数据库记录。

### API

- `GET /api/papers/stats/tc-pressure`：Tc-pressure 默认数据。
- `GET /api/papers/stats/tc-year`：Tc-year 默认数据。
- 未来新增用户图表配置读取、保存、候选点搜索和导出数据接口。

## 数据模型与数据流

导出数据表字段顺序固定为压强、年代、Formula、Tc、DOI。用户配置保存隐藏记录 ID、添加记录 ID、图表类型和更新时间。

## 验收标准

- 两张图桌面端并排。
- 77K/300K 虚线清晰。
- 导出字段顺序固定。
- 个人图表不影响默认图表。
