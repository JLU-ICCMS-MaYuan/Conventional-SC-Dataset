# 07 研究者社区与图表论坛后端设计

## 服务定位

负责研究者身份、贡献可见性、社区图表和未来论坛互动。

## 核心后端设计

- 默认图表继续由 `superconductor_records` 和图表规则生成。
- 用户自定义图表保存为个人配置，不影响全站默认图表。
- 删除点表示从个人图表隐藏，不删除数据库记录。

## 数据模型

导出数据表字段顺序固定为压强、年代、Formula、Tc、DOI。用户配置保存隐藏记录 ID、添加记录 ID、图表类型和更新时间。

## 权限与审核

- 普通用户只能提交或查看自己有权限访问的数据。
- 管理员负责审核、维护和批量操作。
- 涉及公开展示的数据必须保留审核状态和来源信息。

## 风险控制

- 数据库结构变更必须通过单独 migration 方案评审。
- 批量写入和批量审核需要 dry-run 或影响范围汇总。
- 任何未来规划能力不能伪装为当前已落地能力。

## 验收标准

- 两张图桌面端并排。
- 77K/300K 虚线清晰。
- 导出字段顺序固定。
- 个人图表不影响默认图表。
