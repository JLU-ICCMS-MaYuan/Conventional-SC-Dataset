# 01 去中心化超导数据上传前端设计

## 页面定位

负责让研究者提交论文、超导参数记录和晶体结构，是数据进入 SC-Wiki 的第一入口。

## 页面入口

- 保留 `/share` 与 `/compound/{element_symbols}` 作为上传入口，页面右上角展示「有待建设」。
- 统一 DOI、论文元数据、压强、空间群、Tc、结构文件和超导参数录入流程。
- 批量上传界面需要展示字段映射、清洗状态、错误行和人工确认入口。

## 交互原则

- 已落地能力正常展示，未落地能力统一使用「有待建设」标识。
- 页面只展示当前用户能理解和操作的内容，不把后端内部状态暴露成复杂表单。
- 表格、图表和上传控件保持现有 SC-Wiki 视觉风格，优先复用已有组件和样式。

## 状态设计

- 加载中：显示明确的状态文案。
- 空结果：说明当前没有可展示数据。
- 失败：展示可读错误，不吞掉后端错误原因。
- 未登录：提示登录后再使用上传、自定义或管理能力。

## 验收标准

- 结构解析失败不入库。
- 同一压强下默认结构可追溯。
- 清洗数据可导出给 GNN 建模。
