# 代表结构查询与下载

## 功能说明

为超导材料或物性记录选择符合条件的代表结构，并按权限提供原始结构内容下载。

## 当前行为

- 查询可以按超导体和可选空间群选择代表结构。
- 代表项优先使用已批准的默认结构，并支持按超导记录匹配压力等条件。
- `/api/structures/by-property/{kp_id}`（Python 侧）仍按 `key_properties.structure_text` 读取结构文本，并同时返回同材料的已批准结构表记录作为参考。**待核验**：普通物性表已无 `structure_text` 列（结构文本改由 `structure_models` 承载），该端点在当前模型下能否返回结构尚未实测确认；接口需登录，未在本次核对中验证。
- 原始结构下载会检查记录状态、提交者和管理员身份。

## 工作流程

请求确定材料、物性记录或结构 ID；服务过滤批准状态和匹配条件；选择默认或排序后的代表结构；下载端点执行权限检查后返回原始文本。按物性记录读取结构的分支见上方「待核验」说明。

## 约束

- 未批准结构不会作为普通公开代表结构。
- 非管理员对非公开或非本人结构的访问受限。
- 如果缺少匹配结构，接口返回空结果或未找到错误，不自动生成结构。
- `by-property` 接口要求登录用户，但读取的是物性记录内结构文本，不等同于结构表默认项选择。
