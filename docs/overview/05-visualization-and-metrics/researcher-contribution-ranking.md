# 研究者贡献排行

## 功能说明

根据系统收录的论文和用户关联数据汇总研究者贡献，形成公开排行或统计指标。

## 当前行为

- 后端存在研究者贡献指标计算逻辑。
- 测试文件覆盖贡献排序和统计边界。
- 该能力与公共图表共同构成当前“研究者社区”目录下可证实的功能。

## 工作流程

统计逻辑读取已收录论文、记录或用户关系；按贡献规则聚合计数；排序后返回展示数据。

## 约束

- 贡献值只代表 SC-Wiki 当前收录与关联数据。
- 当前未发现帖子、评论、关注、私信或论坛版块代码，不能将本功能表述为社区论坛。
- 测试存在不表示本次已经执行并通过。
