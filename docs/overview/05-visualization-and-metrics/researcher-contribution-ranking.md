# 研究者贡献排行

## 功能说明

根据系统收录的论文和用户关联数据汇总研究者贡献，形成公开排行或统计指标。

## 当前行为

- Go API `/api/admin/all-users` 会返回用户列表，并为每个用户统计已提交论文数和已审核论文数。
- 管理后台统计区会结合用户数、论文数和待审批用户数展示基础管理指标。
- 当前最新前端主导航未发现公开研究者贡献排行页面。

## 工作流程

统计逻辑读取用户与论文上传、审核关系；按用户聚合 `submitted_count` 与 `reviewed_count`；管理后台使用该结果辅助审批和管理。

## 约束

- 贡献值只代表 SC-Wiki 当前收录与关联数据。
- 当前未发现帖子、评论、关注、私信或论坛版块代码，不能将本功能表述为社区论坛。
- 当前公开排行入口未从最新 React 路由中确认。
- 测试存在不表示本次已经执行并通过。
