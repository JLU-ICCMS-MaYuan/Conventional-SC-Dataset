# 可视化与统计

## 功能边界

该功能负责从公开物性记录生成 Tc 年代、压力关系图表数据，以及研究者贡献排行。它不负责通用论坛、社交关系或任意分析报表。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [Tc 历史与压力图表](tc-history-and-pressure-charts.md) | 生成并展示 Tc-year 和 P-Tc 数据 | 公开超导记录、Chart.js |
| [研究者贡献排行](researcher-contribution-ranking.md) | 按已收录数据汇总贡献指标 | 论文与用户关联数据 |

## 功能组成

```text
可视化与统计
├── Tc 历史与压力图表
└── 研究者贡献排行
```

## 关联关系

后端按可见性和数值优先级筛选超导记录，前端首页将结果绘制为实验/理论数据点和参考线。贡献排行复用已收录论文及用户关系，不提供帖子、评论、关注等社区互动能力。
