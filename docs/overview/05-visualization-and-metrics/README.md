# 可视化与统计

## 功能边界

该功能负责从关键物性记录生成 Tc 年代、压力关系图表数据，支持按超导类别显示公共散点背景，并通过图表组合叠加管理员或用户维护的数据点。它不负责通用论坛、社交关系或任意分析报表。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [Tc 历史与压力图表](tc-history-and-pressure-charts.md) | 生成并展示 Tc-year 和 P-Tc 数据及图表组合 | `key_properties`、Recharts、图表组合表 |
| [研究者贡献排行](researcher-contribution-ranking.md) | 按已收录数据汇总贡献指标 | 论文与用户关联数据 |

## 功能组成

```text
可视化与统计
├── Tc 历史与压力图表
└── 研究者贡献排行
```

## 关联关系

后端按关键物性名称、主记录标记、压强和年份筛选公共图表数据；前端 `/share` 使用 Recharts 绘制 Tc-Pressure 与 Tc-Year，并允许选择图表组合叠加重点点位。贡献排行当前没有在最新前端主导航中确认独立展示入口，不提供帖子、评论、关注等社区互动能力。
