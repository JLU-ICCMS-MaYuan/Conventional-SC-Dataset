# 认证与审核

## 功能边界

该功能负责用户注册、邮箱验证、JWT 登录、角色权限、管理员审批，以及论文和超导记录审核管理。它不负责业务数据检索算法或第三方单点登录。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [注册、登录与 JWT](registration-login-and-jwt.md) | 两阶段注册、凭据校验和访问令牌 | 邮件服务、用户模型 |
| [角色与管理员审批](roles-and-administrator-approval.md) | 管理 user/admin/superadmin 角色和审批状态 | 超级管理员权限 |
| [论文与记录审核](literature-and-record-review.md) | 审核、编辑、删除及图表可见性管理 | 管理员权限、论文与记录模型 |

## 功能组成

```text
认证与审核
├── 注册、登录与 JWT
├── 角色与管理员审批
└── 论文与记录审核
```

## 关联关系

注册验证创建或激活用户身份，登录签发 JWT。普通用户直接标记为已批准，管理员申请需要超级管理员审批。已批准管理员可以处理论文与超导记录，部分用户和角色操作仅限超级管理员。
