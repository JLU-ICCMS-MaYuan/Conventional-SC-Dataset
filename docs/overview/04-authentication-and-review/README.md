# 认证与审核

## 功能边界

该功能负责邮箱注册、JWT 会话、用户中心、公开研究身份、管理员资格申请、论文审核以及超级管理员的内容与账号治理。邮箱验证当前停用。它不负责业务数据检索算法或第三方单点登录。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [注册、登录与 JWT](registration-login-and-jwt.md) | 账号创建、凭据校验、会话撤销和前端本地会话 | Go API、JWT、bcrypt |
| [角色与管理员审批](roles-and-administrator-approval.md) | 用户中心、公开资料、管理员资格申请和账号治理 | 账户 API、超级管理员 API、审计模型 |
| [论文与记录审核](literature-and-record-review.md) | 管理员论文审核与超级管理员的图表、快讯和治理工作台 | 分级权限、论文与关键物性模型 |

## 功能组成

```text
认证与审核
├── 注册、登录与 JWT
├── 角色与管理员审批
└── 论文与记录审核
```

## 关联关系

注册只创建普通用户并由前端立即登录，不经过邮箱验证或账号审批。用户在“用户中心”维护公开研究资料、账户安全并申请管理员资格；管理员进入 `/admin` 审核论文，超级管理员进入 `/superadmin` 复用同一审核能力并管理图表、快讯、管理员申请、用户角色、账号状态与审计。
