# 认证与审核

## 功能边界

该功能负责用户注册、JWT 登录、角色权限、管理员审批，以及论文、关键物性、图表组合和快讯内容的管理审核。它不负责业务数据检索算法或第三方单点登录。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [注册、登录与 JWT](registration-login-and-jwt.md) | 账号创建、凭据校验、访问令牌和前端本地会话 | Go API、JWT、bcrypt |
| [角色与管理员审批](roles-and-administrator-approval.md) | 管理 user/admin/superadmin 角色和审批状态 | 管理员 API、用户模型 |
| [论文与记录审核](literature-and-record-review.md) | 审核、编辑、删除论文和关键物性，并管理快讯与图表组合 | 管理员权限、论文与关键物性模型 |

## 功能组成

```text
认证与审核
├── 注册、登录与 JWT
├── 角色与管理员审批
└── 论文与记录审核
```

## 关联关系

注册创建未审批用户，登录签发 JWT。Go 服务要求用户已批准后才能登录，管理员和超级管理员才能进入管理后台。已批准管理员可以处理论文、关键物性、快讯和图表组合，部分用户和角色操作仅限超级管理员。
