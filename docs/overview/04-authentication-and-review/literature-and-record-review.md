# 论文与记录审核

## 功能说明

为管理员提供论文和超导记录的待审核列表、状态变更、编辑删除和图表可见性管理。

## 当前行为

- 审核状态限制为 `pending`、`approved`、`rejected` 和 `needs_revision`。
- 管理员可以查看待审核或全部论文，执行单篇和批量审核，并编辑、删除论文。
- 管理接口可以筛选超导记录并批量更新 `show_in_chart`。
- 部分删除和全局管理操作要求超级管理员。

## 工作流程

管理页面请求审核列表；管理员选择论文或记录并提交状态；后端校验权限和状态值；更新数据库；图表与公开查询随后按审核及可见性条件筛选数据。

## 约束

- 所有审核操作需要有效且已批准的管理员身份。
- 前端文献列表请求 `/api/admin/papers`，当前后端列表路由包含 `/api/admin/papers/all`，契约存在不一致。
- 删除属于不可逆数据操作，必须由上层流程明确确认。
