# 论文与物性结果

## 功能说明

把材料检索命中项组织为论文、超导体和物性记录结果，供详情展示、统计与审核功能复用。

## 当前行为

- 领域关系为元素、化学体系、超导体、超导记录和论文的关联链。
- 论文 API 返回 DOI、标题、作者、年份及关联物性数据，并支持按搜索模式组织结果。
- 超导记录包含实验/理论 Tc、压力、类别和图表可见性等信息。

## 工作流程

材料检索先确定超导体；API 加载关联论文及记录；序列化层将关系转换为页面和导出所需的数据结构；统计与审核模块复用相同记录。

## 约束

- 结果准确性取决于主业务数据库中的关联关系和审核状态。
- 前端存在论文上传请求，但当前 `papers.py` 未发现对应的创建路由，在线上传行为待核验。
