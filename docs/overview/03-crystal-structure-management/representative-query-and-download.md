# 代表结构查询与下载

## 功能说明

为超导材料或物性记录选择符合条件的代表结构，并按权限提供原始结构内容下载。

## 当前行为

- 查询可以按超导体和可选空间群选择代表结构。
- 代表项优先使用已批准的默认结构，并支持按超导记录匹配压力等条件。
- 原始结构下载会检查记录状态、提交者和管理员身份。

## 工作流程

请求确定材料或记录；服务过滤批准状态和匹配条件；选择默认或排序后的代表结构；下载端点执行权限检查后返回原始文本。

## 约束

- 未批准结构不会作为普通公开代表结构。
- 非管理员对非公开或非本人结构的访问受限。
- 如果缺少匹配结构，接口返回空结果或未找到错误，不自动生成结构。
