# 晶体结构管理

## 功能边界

该功能负责 CIF/POSCAR 文本的校验和元数据提取、结构提交与审核、默认结构选择、代表结构查询和原始内容下载。它不负责结构生成、材料科学计算或完整前端工作台。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [格式校验与存储](format-validation-and-storage.md) | 解析结构文本、计算摘要并保存元数据 | pymatgen、结构模型 |
| [上传、审核与默认结构](upload-review-and-default-selection.md) | 管理 pending/approved/rejected 状态和默认项 | 用户认证、管理员权限 |
| [代表结构查询与下载](representative-query-and-download.md) | 匹配超导记录、选取代表结构并控制下载 | 已批准结构、访问权限 |

## 功能组成

```text
晶体结构管理
├── 格式校验与存储
├── 上传、审核与默认结构
└── 代表结构查询与下载
```

## 关联关系

上传首先经过格式校验并进入待审核状态。管理员批准后，同一“超导体、压力、空间群”身份只保留一个默认结构。查询接口仅从满足条件的结构中选择代表项，原始内容下载还会执行权限检查。
