# 数据模型与维护

## 功能边界

该功能负责主业务数据的结构定义、数据库连接、初始化、迁移以及离线 JSON 导入导出。它不负责在线审核决策、外部数据集索引构建细节或 RAG 独立数据库的生命周期。

## 小功能目录

| 小功能 | 职责 | 依赖 |
| --- | --- | --- |
| [领域模型与数据库结构](domain-model-and-schema.md) | 定义元素、材料、论文、记录、结构和用户关系 | SQLAlchemy |
| [数据库初始化与迁移](database-initialization-and-migrations.md) | 建表、填充周期表并执行版本迁移 | Alembic、启动脚本 |
| [数据导入与导出](data-import-and-export.md) | 离线交换用户、论文、记录和结构数据 | JSON、主业务数据库 |

## 功能组成

```text
数据模型与维护
├── 领域模型与数据库结构
├── 数据库初始化与迁移
└── 数据导入与导出
```

## 关联关系

领域模型是所有主业务 API 的共同数据契约。启动流程先应用 Alembic 迁移，再执行初始化；导入导出工具直接使用相同模型和会话。不同启动入口对默认数据库文件和迁移执行方式存在差异。
