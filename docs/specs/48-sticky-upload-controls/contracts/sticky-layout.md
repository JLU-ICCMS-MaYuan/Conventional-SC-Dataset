# UI 契约：固定导航与解析操作栏

## 左侧主导航

- 生产者：`AppShell`
- 消费者：所有由 App Shell 承载的页面
- 语义角色：`navigation`，可访问名称为“主导航”
- 桌面行为：位于 72px 顶部 App Bar 下方，在文档滚动时保持可见
- 高度：不超过 `100vh - 72px`
- 溢出：导航内容过高时只在导航内部纵向滚动
- 层级：低于 App Bar，高于普通正文 Surface

## 当前解析任务操作栏

- 生产者：`UploadPage`
- 可见条件：存在 `activeTaskId`
- 语义角色：`region`，可访问名称为“当前解析任务操作”
- 内容：当前文件名、当前阶段、加载状态、“收起解析”按钮
- 定位：在当前解析详情卡片范围内 sticky，顶部偏移必须大于或等于 App Bar 高度
- 收起按钮可访问名称：`收起当前解析详情`
- 点击结果：清除前端当前详情选择和对应 localStorage 活动任务键；不调用取消、删除或清理 API
- 响应式：文件名可截断，按钮不收缩且保持至少 44px 触摸高度

## 兼容性

- 不改变 `UploadTaskCenter` 的 `onToggle` 入参和任务行按钮语义。
- 不改变上传任务 DTO、HTTP API、轮询或持久化契约。
- 顶部 App Bar 继续保持 72px 高度和现有 z-index。
