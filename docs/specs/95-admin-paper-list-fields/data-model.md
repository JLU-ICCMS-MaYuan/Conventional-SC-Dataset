# 数据模型

不新增实体、关系、唯一索引或迁移。

| 字段 | 含义 | 编辑表示 | 写入表示 |
| --- | --- | --- | --- |
| authors | 有序作者名 | 标签及待确认姓名 | JSON 文本数组 |
| keywords_tags | 有序关键词 | 每行一项文本 | JSON 文本数组 |
| methodology | 有序方法描述 | 每行一项文本 | JSON 文本数组 |

详情原值保存在 editForm；关键词与方法编辑缓冲只在用户输入后创建。
作者待确认输入独立保存，Enter、失焦或保存时并入末尾，新增姓名 trim、拒绝空白和重复。
清空已编辑列表写入字符串 []；未经编辑的 null、空字符串和 JSON 文本保持原值。
输入内部标点不作为分隔符；数组顺序不排序。编辑不新增作者角色业务。
