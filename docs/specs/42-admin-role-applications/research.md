# 技术研究：管理员资格申请

## 决策 1：不复用 is_approved

- **决策**：申请使用独立实体与状态机。
- **理由**：`is_approved` 曾同时影响登录和角色，继续复用会重新混淆注册可用性。
- **备选方案**：给 User 增加 pending role；拒绝，因为历史和多次申请无法表达。

## 决策 2：保存快照而非实时引用

- **决策**：姓名、机构、ORCID、研究方向在提交时复制。
- **理由**：审批期间内容不能静默变化；用户需撤回重提。

## 决策 3：数据库保护单一 pending

- **决策**：使用仅 pending 时非空的生成守卫列并建立唯一约束。
- **理由**：应用层预查无法防止并发重复提交。

## 决策 4：批准与角色更新同事务

- **决策**：锁申请和用户，条件更新 pending 终态。
- **理由**：避免申请已批准但角色未更新，或重复审批。
