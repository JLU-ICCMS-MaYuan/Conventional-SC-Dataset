# Feature 规格：社区 Tc 双图个人配置与品质因子

**GitHub Issue**：[#30](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/30)

**创建日期**：2026-08-20

**状态**：已实现并完成验证

## 背景与目标

社区页的 Tc–Pressure 与 Tc–Year 图表目前纵向堆叠，并且只展示单一 Tc 值。目标是在保持公共数据只读和用户间隔离的前提下，让两张图在宽屏并排、分别选择五种 Tc 字段，并为压力图加入 Chris J. Pickard 提出的超导品质因子 S 等值线。

## 用户场景与验收

### 用户故事 1：并排比较两张公共图表（优先级：P1）

用户希望在桌面端同时比较压力与年份两个视角，在窄屏仍能清晰阅读。

**优先级理由**：直接解决当前页面最明显的布局和可读性问题。

**独立验收**：在 1440 px 宽视口中两图同一行，在手机宽度中自动单列且无页面横向滚动。

**验收场景**：

1. **假如**用户使用宽屏访问社区页，**当**两图加载完成，**那么**两张卡片等宽并排。
2. **假如**用户使用窄屏访问社区页，**当**页面布局响应视口变化，**那么**两图纵向排列且控件和绘图区不溢出。

### 用户故事 2：独立选择并保留 Tc 字段（优先级：P1）

注册用户希望为两张图分别选择实验或不同理论方法的 Tc，并在刷新后保留选择。

**优先级理由**：这是本 Feature 的核心数据能力，并决定后端契约和隐私边界。

**独立验收**：登录用户可将两图设为不同字段，刷新后恢复；切换账号或退出登录后不串用配置。

**验收场景**：

1. **假如**没有有效个人配置，**当**用户打开社区页，**那么**两图都使用 `experimental_tc`。
2. **假如**用户已登录，**当**分别切换两图字段并刷新，**那么**各自选择恢复且公共数据未被修改。
3. **假如**同一浏览器切换账号，**当**新账号打开页面，**那么**只加载新账号自己的配置或默认值。
4. **假如**所选字段在某记录上为空，**当**图表生成数据，**那么**该记录被跳过且不回退到其他字段。

### 用户故事 3：用品质因子评估 Tc–Pressure 数据（优先级：P2）

研究者希望同时看到高 Tc 与低压力的综合评价，而不是只比较单一坐标。

**优先级理由**：提升科学解释力，但不阻断字段选择和布局的基础价值。

**独立验收**：压力图根据当前坐标域动态显示 S 等值线、77 K 与 300 K 参考线，年份图不显示这些覆盖层。

**验收场景**：

1. **假如**Tc–Pressure 图可见，**当**坐标域或尺寸改变，**那么**S 等值线按 `Tc=S×sqrt(39²+P²)` 重算并保持正确标注。
2. **假如**用户查看图例和 Tooltip，**当**比较实验与计算数据，**那么**无需只依赖颜色即可辨别类别，且当前 Tc 字段明确可见。

### 边界与异常场景

- 非法 `tc_field` 请求返回 HTTP 400，不静默回退。
- API 失败、字段无数据和正常结果必须呈现不同状态；字段无数据时仍允许切换字段或恢复默认。
- 本地配置损坏或包含未知字段时忽略损坏内容并恢复默认。
- 匿名用户可在当前会话切换字段，但刷新后恢复公共默认，不持久化个人配置。
- 仅 `show_in_chart=true` 且关联论文为 `approved` 的记录进入公共图表；无论文关联记录不公开。

## 需求

### 功能需求

- **FR-001**：系统必须在宽屏将 Tc–Pressure 与 Tc–Year 两张图并排，在窄屏自动切换为单列且无横向溢出。
- **FR-002**：两张图必须各自提供五个 Tc 字段的独立单选，默认均为 `experimental_tc`。
- **FR-003**：所选字段为空或非有限数值的记录必须被排除，且不得回退到其他 Tc 字段。
- **FR-004**：图表标题、Y 轴、Tooltip 和结果状态必须明确当前 Tc 字段。
- **FR-005**：注册用户的两图选择必须按稳定用户标识隔离保存在本地浏览器；匿名用户不得持久化该配置。
- **FR-006**：用户必须能够恢复默认，仅清除当前用户图表配置并将两图恢复为 `experimental_tc`。
- **FR-007**：公共统计接口必须仅接受五个字段的静态白名单，缺省使用 `experimental_tc`，非法值返回 HTTP 400。
- **FR-008**：公共数据必须来自 `superconductor_records` 中 `show_in_chart=true`、关联 Approved 论文且所选字段有效的记录；压力图还要求压力有效，年份图还要求年份有效。
- **FR-009**：公共缓存必须按图表类型和规范化 Tc 字段隔离，个人身份和偏好不得进入服务端缓存。
- **FR-010**：Tc–Pressure 图必须动态显示 Pickard S 等值线，计算式为 `S=Tc/sqrt(39²+P²)`，并显示 77 K、300 K 水平参考线。
- **FR-011**：实验与计算数据必须同时使用颜色之外的编码区分，并在 Tooltip 中提供文本类别。
- **FR-012**：个人配置不得写入 MySQL、Redis 或公共记录，也不得修改论文、材料、压力、年份或 Tc 原始值。
- **FR-013**：散点详情抽屉、DOI 跳转、现有类型图例和图表组合叠加能力不得回归。

### 关键实体

- **Tc 字段**：五值枚举，决定单张图的 Y 值来源。
- **个人图表配置**：由用户 ID 命名空间、压力图字段、年份图字段和版本组成；生命周期限于当前浏览器。
- **公共图表点**：来自可公开记录，包含坐标、材料、实验/计算类别、超导类型、论文标识和当前 Tc 字段。
- **品质因子等值线**：由 S 档位和当前压力坐标域派生，不持久化。

## 成功标准

- **SC-001**：1440 px 宽度下两图同一行，390 px 宽度下单列且页面无横向滚动。
- **SC-002**：五个白名单字段在两图中均可独立选择，默认、刷新恢复、账号切换和恢复默认场景全部通过。
- **SC-003**：非法字段请求 100% 返回 HTTP 400；不同字段请求不会命中彼此的缓存结果。
- **SC-004**：抽样点的 S 曲线计算误差不超过 0.1 K，并正确显示 77 K、300 K 参考线。
- **SC-005**：Go 自动化测试、前端生产构建和浏览器验收清单全部通过，详情与 DOI 交互无回归。
- **SC-006**：实现不包含个人配置 API、MySQL schema 变化或服务端个人配置写入。

## 假设与依赖

- `User.id` 是浏览器本地配置命名空间所需的稳定、非敏感标识。
- `superconductor_records` 是五个 Tc 字段的权威来源；`show_in_chart` 与 Approved 论文共同构成公共准入边界。
- #17 的筛选与旧组合退役尚未落地；本 Feature 保留当前组合能力，并确保后续筛选可基于 `tc_field` 契约叠加。
- 默认 S 档位采用 `0.2、0.5、1、2、3`，超出当前 Y 域的曲线段不绘制。

## 范围外事项

- 跨设备同步、公开分享或协作编辑个人配置。
- 修改数据库 schema、持久化 S 或覆盖原始科研数据。
- 在本 Feature 中删除旧 ChartGroup 表或完成 #17 的全部筛选改造。
- 新增图表图片/CSV 导出能力或引入新的前端测试框架。
