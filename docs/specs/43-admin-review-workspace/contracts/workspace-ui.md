# 管理员工作台 UI 契约

## 路由矩阵

| 当前身份 | `/admin` | `/superadmin` |
|---|---|---|
| 未登录 | 登录提示 | 登录提示 |
| user | 403 | 403 |
| admin | 管理员工作台 | 403 |
| superadmin | 重定向 `/superadmin` | 超级管理员工作台 |

## `ReviewWorkspace`

输入仅包含当前角色可用的审核能力和可选初始筛选；组件自行处理论文列表、详情、编辑、审核、批量动作、加载、错误和空状态。不得请求用户、图表、快讯、申请或审计接口。

## `WorkspaceOverview`

管理员模式只显示论文总数、待审数和当前身份。超级管理员模式可由 #44 注入额外治理统计，但不得改变审核统计语义。
