# 论文历史展示契约

## 接口

`GET /api/admin/papers/:id/history` 保持现有契约：登录管理员或超级管理员可访问，普通用户 403，未登录 401。论文不存在 404，查询失败 500。

响应保留 `paper_id` 与 `events`。事件包含 `id`、`event_type`、`paper_revision`、`actor.username`、`actor.unknown`、`occurred_at`、可空的 `review.status/comment`。按时间和 ID 升序返回，不新增名称字段。

## 界面

- 管理员与超级管理员工作台共用历史弹窗；普通用户访问这两个工作台均被角色守卫拒绝。
- 每条事件保留类型标题，增加名称 `YYYY-MM-DD-HH-mm-vN-操作者-简介`。对于审核事件，操作者就是审核人，简介就是审核意见。
- 时间取浏览器本地时区；年月日和时分补零。
- 审核评论连续空白合并为一个空格；完整正文仍独立显示。
- 审核缺失评论为“未填写审核意见”，缺失审核人为“未知审核人”；上传/修改使用对应事件类型，导入者未知使用原有提示。
- 日期非法显示“时间未知”；长名字换行，事件 ID 保持唯一性。
- 固定文案支持中文和英文，姓名及意见不翻译。

## 兼容性

旧事件按原字段直接显示；不迁移、不改写历史数据，不向普通详情 API 增加内部字段。
