# papervision 论文版本可见性与命名规格

关联 Issue：[#93](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/93)

## 现状与默认约定

papervision 在本需求中指管理员工作台的论文历史弹窗。当前前后端已经限制管理员角色访问；本次固定其回归覆盖并更新名称。时间沿用浏览器本地时区，精确到分钟。名称是每次历史事件的展示标签，不是新的持久化版本标识；同一版本的多次审核仍各自保留。

## 用户故事

- **US1（P1）**：作为管理员或超级管理员，我需要查看论文历史版本，以便审核与追溯。假如我已登录对应工作台，点击历史后能读取论文事件。
- **US2（P1）**：作为管理员，我需要从版本名称直接识别时间、版本号、审核人和审核简介。假如一条审核发生在本地时间 2026 年 9 月 4 日 18:00、版本为 1、审核人为 reviewer、意见为“证据充分”，打开历史后显示 `2026-09-04-18-00-v1-reviewer-证据充分`。
- **US3（P1）**：作为普通用户，我不能读取论文历史中的内部审核信息。假如我直接访问管理员工作台或历史 API，得到 403；未登录请求 API 得到 401。

## 功能需求

- **FR-001**：论文历史接口只允许 `admin` 与 `superadmin` 角色访问，普通用户返回 403。
- **FR-002**：历史弹窗中的每个版本名称必须使用 `YYYY-MM-DD-HH-mm-vN-审核人-审核简介` 格式。
- **FR-003**：时间和版本号取历史事件的 `occurred_at` 与 `paper_revision`；审核人取事件中的操作者快照。
- **FR-004**：审核简介取审核评论，名称中将连续空白合并为空格，正文保留原始内容；空评论使用“未填写审核意见”，未知审核人使用“未知审核人”。上传、修改事件对应位置使用实际操作者及“上传”或“修改”，不把操作者称为审核人；历史导入仍保留上传者未知提示。以上固定文案随中英文语言切换。
- **FR-005**：现有审核状态、评论正文和时间线顺序保持不变。

## 成功标准

- **SC-001**：Go 权限测试证明 user 为 403，admin/superadmin 可成功读取。
- **SC-002**：前端显示名称包含日期、时间、`vN`、审核人和简介，空字段不导致渲染异常。
- **SC-003**：Go 与前端定向测试通过，Issue、Spec 与 Overview 链接有效。

## 范围外

不改变审核状态流转、历史事件写入模型、普通论文详情权限或历史数据迁移。

## 边界情况

长意见允许自动换行，不截断或改写数据库评论；同分钟同版本的审核通过事件 ID 区分，展示名无唯一性要求。日期非法时显示“时间未知”，不显示 NaN；空历史、加载失败和重试沿用现有行为。

## Documentation Impact

完成后更新[论文与记录审核](../../overview/02_Decentralized_Maintenance_and_Verification/literature-and-record-review.md)，记录管理员专属历史访问与版本名称格式；根 README 操作流程没有变化。
