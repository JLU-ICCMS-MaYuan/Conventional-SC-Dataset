# 实施计划：论文查询权限与重复跳转

## 方案

Go 保持 `/api/papers/**` 唯一拥有者，新增可选鉴权和统一可见性策略。Handler 先查询存在性，再依据身份决定 403/结果，并使用显式 DTO 构造字段。SQLAlchemy 与 Go 模型同步 `admin_internal_note`。前端详情和重复提示统一使用 `/api/papers/{id}`。

## 阶段

1. 先写 Go 权限矩阵、字段泄漏、PATCH 白名单和重复动作测试。
2. 实现可选鉴权、策略函数与安全 DTO。
3. 新增内部备注迁移并同步 Python/Go 模型。
4. 统一前端论文详情和重复跳转。
5. 验证 approved-only 搜索、RAG 和统计回归。
