# 技术研究：全新空库的条件化超导数据模型

## 决策 1：论文 revision 是唯一审核边界

**决策**：`papers.content_revision` 表示当前科学内容版本，`approved_revision` 只在整篇审核
通过时等于它；科学子实体保存 `paper_revision`，不保存审核状态。

**理由**：论文级和结果级双审核会产生状态漂移。用户要求一次审核确认论文全部 Tc，并覆盖
同 revision 的结构、普通物性和 Evidence。

## 决策 2：只建立空库目标 Schema

**决策**：目标 revision 检测到现有业务数据时失败，不读取或转换旧数据。

**理由**：用户明确两个现有数据库均不迁入；历史回填属于后续独立 Issue。

## 决策 3：组分身份包含同位素

**决策**：保留 `chemical_systems → superconductors`；`composition_key` 表达含同位素的规范
组分身份，`isotope_signature` 只保存于 `superconductors`。

**理由**：LaH10 与 LaD10 是不同组分，同位素不是压力状态。

## 决策 4：材料状态承载物相和外部条件

**决策（由 Issue #50 修订）**：`material_states` 保存压力、温度、外场和报告空间群；不建立材料+压力唯一键，`phase_label` 不再属于数据模型。

**理由**：同一论文同一名义压力可报告竞争相；结构重复保存物相会产生漂移。

## 决策 5：论文之间保持独立

**决策**：每个状态、结构、上下文和结果绑定来源论文 revision；跨论文相同结构不自动复用。

**理由**：论文 B 即使采用与 A 相同几何，也应保存 B 自己使用或计算的结构版本，A、B 可
独立审核和公开。

## 决策 6：分开结构、声子和 Tc 方法

**决策**：结构核处理存于 `structure_models`，声子/EPC 核处理存于
`calculation_contexts`，Tc 方法存于 `tc_results`。

**理由**：量子非谐结构不意味着声子和 Tc 求解采用相同近似。

## 决策 7：Tc 使用纵向结果与显式代表选择

**决策**：每个方法/参数/判据结论一行，理论和实验上下文互斥；代表 Tc 由审核者指定。

**理由**：横向五列不能表达同方法多参数；代表结果只影响默认展示。

## 决策 8：普通物性使用定义表与实例表

**决策**：`property_definitions` 保存规范代码、名称、单位和值类型；
`superconductor_properties` 保存论文原文和可选规范值；Tc 不进入普通物性表。

**理由**：属性词典便于检索，但规范化不能覆盖论文原文。

## 决策 9：原文优先

**决策**：原始名称、值、单位为展示主字段；规范值、范围和单位用于筛选与比较。

**理由**：论文原文是审核依据，规范化是派生解释。

## 决策 10：组合外键保护 revision

**决策**：状态、结构、上下文、结果、普通物性和 Evidence 连接携带论文及 revision，
通过组合外键阻止跨论文、跨版本串线。

**理由**：Python、Go 和脚本均可能写库，核心不变量不能只靠单一服务层。

## 决策 11：#12 与 #13 边界

**决策**：#32 取代 #12 的唯一结构样本和历史迁移目标；#13 收缩为 GNN 导出投影比较，
不得改变核心库跨论文独立记录。

**理由**：核心库保存来源事实，训练投影可以按任务生成去重视图。
