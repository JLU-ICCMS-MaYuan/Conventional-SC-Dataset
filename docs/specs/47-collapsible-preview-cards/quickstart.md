# 快速验收：AI 临时表单字段卡片渐进展开

## 前置条件

- 工作目录为 SC-Wiki 仓库根目录。
- `frontend/node_modules/` 已安装且版本与 `frontend/package.json` 一致。
- 不需要启动后端服务即可运行自动化测试。

## 自动化验证

### 1. 运行上传工作区测试

```bash
cd frontend
npm run test:upload-ui
```

预期：`tests/01_decentralized_uploading/` 下全部 Vitest 测试通过，包括短内容、长内容、独立展开、再次收起、动态追加、任务切换和键盘语义场景。

### 2. 运行生产构建

```bash
cd frontend
npm run build
```

预期：TypeScript 编译和 Vite 构建成功，无新增类型或打包错误。

## 浏览器验收

1. 打开 `/upload` 并查看一个处于解析中的任务。
2. 在“AI 临时表单”确认短字段完整显示且没有“展开”按钮。
3. 确认作者、长摘要或多候选字段默认收起，标题和状态仍可见。
4. 连续展开至少三张长卡片，再收起其中一张；其他卡片保持展开。
5. 选择并复制正文或来源文字，确认卡片不误触切换。
6. 缩窄浏览器到单列，确认无横向滚动，展开控制仍正确。
7. 使用 Tab、Enter 和 Space 操作展开按钮，确认焦点可见且读屏语义包含字段名和展开状态。

## 回归边界
