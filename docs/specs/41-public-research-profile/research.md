# 技术研究：公开科研身份页

## 决策 1：独立公开 DTO

- **决策**：公开 Handler 显式构造响应。
- **理由**：Go User 当前包含邮箱、审批和状态字段，直接序列化容易越权泄漏。
- **备选方案**：复用 `/auth/me`；拒绝，因为匿名和本人权限完全不同。

## 决策 2：用户名地址不做别名

- **决策**：按唯一用户名查询，改名后旧 URL 404。
- **理由**：自助改名是有限历史能力，为少量旧地址建立别名表不符合范围。

## 决策 3：页面级 noindex

- **决策**：组件挂载时设置 robots meta，卸载时恢复。
- **理由**：项目没有 Head 管理库，且不能把 noindex 写成全站静态配置。

## 决策 4：排行榜只增加链接

- **决策**：继续使用已有 username 字段构造路由。
- **理由**：不需要让高缓存接口携带实名、机构或角色。
