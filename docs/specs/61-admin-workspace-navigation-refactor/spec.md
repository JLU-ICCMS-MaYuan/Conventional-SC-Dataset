# Feature 规格：管理员工作台导航改为卡片式入口

**GitHub Issue**：[#61](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/61)

**创建日期**：2026-08-31

**状态**：已实现

## 背景与目标

管理员与超级管理员工作台此前有两层入口：顶部 Tabs（概览、论文审核、用户与权限、
图表管理、快讯管理）和「概览」页内的统计卡片（用户总数、论文总数、待审批管理员、
当前角色）。两者内容重复，且名称不统一——「论文总数」卡片跳转到的页面叫「论文审核」。

本 Feature 移除顶部 Tabs，把统计卡片本身变成功能入口，使工作台首页即导航。

## 用户场景与验收

### 用户故事 1：管理员从卡片进入论文审核（P1，已实现）

普通管理员登录后看到工作台首页，直接看到卡片，点击即进入对应功能。

**独立验收**：页面无顶部 Tabs；卡片可点击且跳转正确。

**验收场景**：

1. **假如** 普通管理员访问 `/admin`，**当** 页面加载，**那么** 显示 2 张卡片：
   「论文审核」（可点击，显示论文数）与「当前角色」（不可点击）；页面无 Tabs。
2. **假如** 管理员点击「论文审核」卡片，**当** 跳转完成，**那么** 显示论文列表，
   卡片名称与目标页面标题一致。

### 用户故事 2：超级管理员从卡片进入各治理功能（P1，已实现）

**独立验收**：超管看到 6 张卡片，5 张可点击且各自跳转正确。

**验收场景**：

1. **假如** 超级管理员访问 `/superadmin`，**当** 页面加载，**那么** 显示 6 张卡片：
   用户与权限、论文审核、待审批管理员、图表管理、快讯管理（均可点击）与当前角色
   （不可点击）；页面无 Tabs。
2. **假如** 超管用键盘 Tab 键遍历，**当** 焦点落在可点击卡片上，**那么** 出现可见
   焦点指示，按 Enter 可激活——卡片必须对键盘与读屏用户可达。

### 边界与异常场景

- 「当前角色」纯身份展示，无目标页面，故不做成可点击卡片
- 统计数据未加载完时显示占位符而非 `0`，避免被误读为真实值为零
- 「快讯管理」无对应计数来源，显示 `-`
- 普通管理员不显示超管专属卡片（用户与权限、待审批管理员、图表管理、快讯管理）

## 需求

### 功能需求

- **FR-001**：系统必须移除管理员与超级管理员工作台的顶部 Tabs 导航。
- **FR-002**：系统必须把功能入口呈现为可点击卡片，点击后进入对应功能视图。
- **FR-003**：普通管理员必须只看到「论文审核」与「当前角色」两张卡片。
- **FR-004**：超级管理员必须看到 6 张卡片：用户与权限、论文审核、待审批管理员、
  图表管理、快讯管理、当前角色。
- **FR-005**：可点击卡片必须具备鼠标悬停反馈，且对键盘操作与辅助技术可达（具备
  按钮语义、可聚焦、可用 Enter 激活）。
- **FR-006**：卡片名称必须与其目标功能页面的名称一致，消除「论文总数 vs 论文审核」
  这类不一致。
- **FR-007**：统计数据尚未加载时，卡片必须显示占位符而非 `0`。

### 关键实体

本 Feature 不涉及数据实体，仅调整前端导航呈现。

## 成功标准

- **SC-001**：`/admin` 与 `/superadmin` 页面均不含 Tabs 组件。
- **SC-002**：普通管理员看到 2 张卡片，超级管理员看到 6 张。
- **SC-003**：点击各可点击卡片进入正确的功能视图。
- **SC-004**：可点击卡片可被无障碍查询按角色定位（`getByRole('button', { name })`），
  这既是无障碍要求，也让测试无需依赖实现细节。
- **SC-005**：统计未加载时卡片不显示 `0`。

## 假设与依赖

- 工作台内部仍以视图索引切换功能区，卡片点击即切换该索引
- `/admin` 与 `/superadmin` 复用同一 `AdminPage` 组件，按 mode 区分可见卡片

## 范围外事项

- 不改动各功能视图自身的内容与布局
- 不引入前端路由级页面拆分，仍在单页内切换
- 不新增功能入口，只重组既有入口
- 「快讯管理」的计数来源不在本轮补齐
