# Feature 规格：重构管理员工作台导航为卡片式入口

**GitHub Issue**：[#61](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/61)

**创建日期**：2026-08-31

**状态**：草稿

## 背景与目标

当前管理员和超级管理员工作台有两层导航：顶部子菜单（概览、论文审核、用户与权限等）和下方统计卡片（用户总数、论文总数等），内容重复且名称不统一。

本 Feature 删除顶部子菜单导航，将所有功能整合为统计卡片形式，点击卡片跳转到对应功能页面，简化导航结构。

## 用户场景与验收

### 用户故事 1：管理员通过卡片式入口访问功能（优先级：P1）

管理员登录后看到工作台首页，显示2张统计卡片（论文审核、当前角色），点击卡片跳转到对应页面。

**验收场景**：
1. **假如** 管理员访问工作台首页，**那么** 显示2张卡片，无顶部子菜单
2. **假如** 管理员点击"论文审核"卡片，**那么** 跳转到论文审核页面

### 用户故事 2：超级管理员通过卡片式入口访问所有功能（优先级：P1）

超级管理员登录后看到6张统计卡片（用户总数、论文审核、待审批管理员、当前角色、图表管理、快讯管理），点击卡片跳转到对应功能。

**验收场景**：
1. **假如** 超级管理员访问工作台首页，**那么** 显示6张卡片，无顶部子菜单
2. **假如** 超级管理员点击各卡片，**那么** 跳转到对应页面

## 需求

### 功能需求

- **FR-001**：系统必须删除管理员工作台的顶部子菜单导航（概览、论文审核、用户与权限、图表管理、快讯管理）。
- **FR-002**：系统必须将所有功能入口整合为可点击的统计卡片。
- **FR-003**：普通管理员必须只显示2张卡片：论文审核、当前角色。
- **FR-004**：超级管理员必须显示6张卡片：用户总数、论文审核、待审批管理员、当前角色、图表管理、快讯管理。
- **FR-005**：可点击卡片必须有明显的视觉反馈（hover 效果、鼠标指针变化）。

## 成功标准

- **SC-001**：管理员工作台无顶部 Tabs 组件。
- **SC-002**：超级管理员工作台显示6张卡片，布局清晰（2行3列）。
- **SC-003**：点击卡片后跳转到正确的功能页面。
