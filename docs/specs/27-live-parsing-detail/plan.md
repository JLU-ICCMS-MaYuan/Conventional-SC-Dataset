# 实施计划：实时解析详情

## 方案

Worker 为每个文件创建稳定 chunk manifest，开始前标记 processing，结果原子落盘后标记 completed。API 通过白名单 DTO 返回 manifest 和清洗结果。前端以 2 秒轮询渲染层级详情。RQ 使用可配置 worker pool/进程数实现论文级并发 2。

## 阶段

1. 先写状态转换、增量读取、安全 DTO、缓存重试和并发配置测试。
2. 实现 chunk manifest、来源定位和原子结果写入。
3. 实现增量详情与局部重试 API。
4. 实现前端层级详情、轮询和失败操作。
5. 验证两个任务并发、取消和重启恢复。

## 依赖

依赖 #25 状态机和 #26 文件标识；汇总草稿继续复用 #23 的用户校对模型。
