# Feature 规格：材料状态多维分类与论文审核内确认

**GitHub Issue**：[#51](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/51)

**创建日期**：2026-08-25
**最近修订**：2026-08-25
**状态**：已确认，替代本 Feature 早期的独立分类治理设计

## 背景与目标

上传校对曾把论文级 `sc_type` 作为自由文本，并以静态英文编码和原生 `datalist` 提供候选。Issue #51 第一版虽接入了数据库目录，却额外建立了独立建议队列、二级审批、目录停用与合并工作流。这套治理流程把论文审核拆成多个页面和多次事务，不符合“解析论文主要研究对象并由审核者一次确认”的目标。

本 Feature 保留材料状态级多维分类，但把 AI 建议视为论文审核草稿和证据。审核者在论文审核页面认可 AI 建议、改选数据库已有分类或创建新分类；批准事务只把人工确认后的目录 ID 写入正式材料状态，并在论文 revision 级审核事件中保存 AI 建议和最终选择快照。

引用工作证据继续供后台区分本文研究对象，但“引用材料”不进入普通界面或最终科学数据。

## 用户故事与验收

### 用户故事 1：数据库驱动的统一分类选择（P1）

论文贡献者和审核者从数据库读取材料家族、结构家族和中文标签。规范中文名、英文名、内部编码及可靠 seed 别名只做确定性精确映射，普通界面不显示内部编码。

**独立验收**：AI 建议 `高压氢化物` 时，界面候选解析为“氢基超导体”，压力仍作为独立 GPa 字段保存。

1. 输入 `hydride`、`氢化物` 或“氢基超导体”均匹配同一目录 ID。
2. 未匹配名称显示为待人工确认，不伪装成数据库已有 ID。
3. 目录读取失败时显示可重试错误，不退回静态候选。

### 用户故事 2：保存独立科学维度（P1）

每个材料状态分别保存材料家族、结构家族、不同元素种类数、压力和材料维度。材料家族单选；结构家族可多选且最多一个主项。

**独立验收**：`LaH10 @ 150 GPa` 保存为“氢基超导体”、元素种类数 2、压力 150 GPa、论文明确的结构家族和材料维度，不创建“高压氢化物”复合目录项。

1. 元素数量表示不同元素种类数，不是化学计量总和。
2. 材料维度使用零维、一维、二维、三维、准一维、准二维和未知。
3. 不根据化学式所含元素推断材料家族；`CeCu2Si2` 等只有在论文明确表述、可靠别名或人工审核后才能归为重费米子超导体。

### 用户故事 3：在论文审核中一次确认（P1）

有论文审核权限的管理员在同一页面完成三种操作：认可已有建议、改选数据库已有分类、输入新分类名称。新分类不要求填写英文名称或内部编码。

**独立验收**：一次 `POST /api/admin/papers/{id}/review` 在同一数据库事务中完成目录精确匹配或创建、材料状态分类写入、完整性校验、论文批准和审核快照写入。

1. 选择已有 ID 时只写入该 ID。
2. 输入新名称时先按规范名和 seed 别名精确查重；没有匹配才创建正式目录项。
3. 任一步失败时，目录项、材料状态、论文状态和审核事件全部回滚。
4. 拒绝或退回论文时不得创建目录项或写入新的最终分类。
5. 重复 `review_request_id` 不得重复创建目录或审核事件。
6. 批量批准不允许绕过逐篇分类确认；批量拒绝和退回仍可使用。

### 用户故事 4：一次性兼容旧草稿（P2）

旧草稿读取时对顶层 `sc_type` 做一次性白名单转换，保存后只保留材料状态级新字段；新接口不再接受旧格式。

1. 已确认旧值确定性转换为正式中文选择。
2. `carbon`、`others` 等歧义值保持待确认，不猜测写入。
3. 旧数据库迁移只接受论文、材料和压力的唯一匹配，其他记录进入报告。

### 用户故事 5：只保留本文正式分类（P1）

只有 `current_paper` 证据可以形成材料状态。`referenced_work` 只作为后台排除误判和审核上下文，不生成正式材料状态、分类关系或公开“引用材料”字段。

## 功能需求

- **FR-001**：每个当前论文 revision 的材料状态保存零或一个材料家族 ID；批准前必须确认。
- **FR-002**：材料家族首批包含氢基、铜基、铁基、镍基、无机硼碳氮基、有机和重费米子超导体七项。
- **FR-003**：结构家族使用数据库目录，可多选且最多一个主项。
- **FR-004**：材料家族、结构家族、不同元素种类数、压力和材料维度必须独立保存。
- **FR-005**：材料维度使用七个受控值；未明确时保存“未知”。
- **FR-006**：系统从确认的规范化化学式计算不同元素种类数；失败时保持空值并阻止批准。
- **FR-007**：不得根据化学式包含某元素自动决定材料家族。
- **FR-008**：材料家族和结构家族候选必须来自数据库，普通响应只返回 `{id, name, aliases}`。
- **FR-009**：上传校对、论文编辑和管理员审核复用共享 MUI `Autocomplete`，不得使用原生 `datalist` 或静态英文候选。
- **FR-010**：规范中文名、规范英文名、内部编码和 seed 别名只做规范化后的精确匹配，不使用模糊匹配自动落库。
- **FR-011**：AI 与贡献者的原始建议只保存在临时审核草稿或论文 revision 审核快照，不建立独立建议审批队列。
- **FR-012**：审核者必须在论文审核页认可已有分类、改选已有分类或输入新分类；批准时一次完成最终落库。
- **FR-013**：新目录名必须执行规范化唯一约束；内部 `code` 自动生成，`name_en` 可空，普通用户不填写也不查看二者。
- **FR-014**：批准事件必须保存 AI 建议、审核上下文和数据库验证后的最终分类快照；正式材料状态只保存最终目录关系。
- **FR-015**：普通界面、普通接口和正式 Schema 不包含 `referenced_materials`、`sc_type`、`type_code` 或 `type_proposal_raw`。
- **FR-016**：只有 `current_paper` 证据形成正式材料状态；`referenced_work` 仅保留在内部审核上下文。
- **FR-017**：旧草稿读取路径一次性转换 `sc_type`；新保存接口拒绝旧格式。
- **FR-018**：`高压氢化物`确定性映射为“氢基超导体”，压力只能来自论文独立抽取的数值或范围。
- **FR-019**：论文批准、最终分类写入、新目录创建和审核事件写入必须处于同一事务。
- **FR-020**：拒绝、退回、旧 revision、跨论文状态或无效目录请求不得产生部分写入。
- **FR-021**：重复 `review_request_id` 必须幂等。
- **FR-022**：材料家族缺失或元素种类数无法确认时不得批准；结构家族缺失和材料维度未知不阻塞批准。
- **FR-023**：目录只提供读取和审核内创建；本 Feature 不提供独立重命名、停用、合并、别名审批或目录审计工作流。
- **FR-024**：批量批准必须拒绝并提示逐篇确认分类；批量拒绝和退回保持可用。

## 关键实体

- **材料家族**：材料状态的单一主要领域分类，拥有稳定 ID、自动内部编码、规范中文名和可空英文名。
- **结构家族**：材料状态的结构拓扑分类，可多选并指定一个主项。
- **可靠别名**：仅由迁移 seed 或明确维护脚本提供，用于精确映射，不提供在线审批工作流。
- **材料状态分类**：材料家族、结构家族、元素种类数、压力和材料维度的组合。
- **论文审核分类快照**：`paper_review_events` 上的 revision 级 JSON，保存审核上下文和数据库验证后的最终选择，不作为公开科学字段。

## 成功标准

- **SC-001**：上传、论文编辑和管理员审核的候选与数据库目录一致，不存在静态材料家族数组。
- **SC-002**：固定中文、英文、编码和 seed 别名样例 100% 映射到同一 ID；未匹配名称不在审核前写入正式 ID。
- **SC-003**：包含本文与引用工作的样例中，公开引用材料字段数量为 0，内部作用域仍可核对。
- **SC-004**：`LaH10`、`CeCu2Si2`、`CeCoIn5`、`UPt3` 和 `UTe2` 的元素种类数及人工确认家族符合规则。
- **SC-005**：数据库保证每个材料状态最多一个主结构家族。
- **SC-006**：认可已有、改选已有、创建新项、失败回滚、拒绝不创建和请求幂等测试全部通过。
- **SC-007**：fresh MySQL 8.4 可从空库执行 `alembic upgrade head`，最终 Schema 不含旧治理表或 `merged_into_id`。
- **SC-008**：Python、Go、前端、TypeScript、生产构建和专项验收测试全部通过。

## 假设、依赖与范围外

- 依赖 #32 和 #46 的 `Paper -> MaterialState -> TcResult` 主路径，以及 #45 的证据作用域判断。
- `0012` 已进入 Git 历史，因此只做 MySQL 8.4 兼容修复；后续迁移负责删除旧治理结构，兼容已执行过 `0012` 的环境。
- 本 Feature 不自动运行生产数据库迁移，不修改生产数据。
- 搜索筛选、压力等级阈值、模糊匹配、完整结构本体、分类父子树和在线别名治理均在范围外。

## 已确认决策

- 分类属于材料状态，不属于整篇论文。
- 高压是独立压力事实，不是材料家族层级。
- AI 只提出建议，人工审核决定正式分类。
- 新材料家族和新结构家族都可在论文批准事务中创建。
- 引用工作只用于后台判断，不进入最终科学数据。
