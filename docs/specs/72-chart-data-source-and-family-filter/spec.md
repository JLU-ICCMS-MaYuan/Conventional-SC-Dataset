# Feature 规格：社区图表数据源迁移到条件化模型，并恢复背景分区与家族筛选

**GitHub Issue**：[#72](https://github.com/JLU-ICCMS-MaYuan/SC-Wiki/issues/72)

**创建日期**：2026-09-01

**状态**：A 组与 B 组均已实现

## 需求分组

本 Feature 分两批推进，同属 Issue #72：

- **A 组（US1–US3，已实现）**：数据源失效的根因修复、动态材料家族分类、空数据仍渲染背景。
- **B 组（US4–US6，已实现）**：在 A 组基础上提出的布局对齐、控件宽度、移除组合选择器、填充配色改版、Tc 字段英文化、年份图温度渐变。

## 背景与目标

社区页（`/share`）的 Tc-Pressure 与 Tc-Year 两张图完全不显示任何内容，即使数据库里已有一篇审核通过的 Hg 文献（`papers.id = 9`，1911 年，Tc 4.2 K）。

根因是数据源表已被删除，而查询代码未同步：

1. `goserver/handlers/stats.go` 的两个图表查询写的是 `FROM superconductor_records sr`，该表在条件化数据模型迁移 `alembic/versions/20260821_0008_add_superconducting_data_model.py:83` 里已 `drop_table`。
2. 查询用 `database.DB.Raw(query).Scan(&rows)`，**未检查 `.Error`**。表不存在的错误被静默吞掉，两个接口恒定返回 `[]`。
3. SQL 依赖的三个字段在新模型下全无对应列：`sr.show_in_chart`（新库无任何 `%chart%` 列）、`sr.superconductor_type`、`sr.article_type`。
4. 前端 `share.tsx` 用 `pressureData.length === 0` 早退渲染 Alert，于是连坐标系与品质因子背景一并消失。

同时暴露两个既有设计的退化：

5. **品质因子区域划分丢失**：`#30` 只实现了 S 等值线，没有区域填充；且空数据时整张图被 Alert 顶掉，背景无从显示。
6. **超导类型分类维度失效**：前端硬编码 7 类（`hydride`/`cuprate`/`iron_based`/…），而新模型的分类是 `material_families` 目录，且允许用户自建家族（本地库第 8 条即用户创建的「单质超导体」），硬编码永远覆盖不到。`ChartGroupEditor` 还把 `state_kind`（`theoretical`/`experimental`/`mixed`/`unknown`，属数据来源性质）误当分类维度使用。

另外发现一个独立的显示 bug：`ChartScatter` 把两条 `ReferenceLine` 包在 React Fragment 里，recharts 按子元素类型分派渲染，Fragment 内的 `ReferenceLine` 不被识别，导致 77 K 与 300 K 参考线在两张图上都不显示。

**A 组目标**：把图表数据源迁到条件化模型，让已审核数据正常上图；恢复并增强品质因子背景分区（空数据时也要显示）；把分类维度改为动态材料家族，并提供多选组合。

### B 组背景

A 组交付后，实际使用暴露出布局与可读性问题：

7. **两图不对齐**：材料家族多选框的显示文本随选中项数量变化，选中项多时文本换行撑高控件，把下方的「组合」选择器与整个图表向下推，导致左右两张图的坐标系不在同一水平线上。选择内容属用户操作，不应影响图表位置。
8. **控件宽度不稳定**：家族选择框用 `minWidth: 220` 且无上限，宽度随选中项文本长度伸缩，两张图之间也不一致。
9. **「组合」选择器已冗余**：材料家族多选已完整承担材料筛选职责，`/share` 页保留的 chart group 选择器及其编辑/复制/导出/新建按钮不再需要。
10. **填充配色需定稿**：A 组的红→黄→绿由实现时临时选定，仓库既无历史实现也无设计稿依据（git 历史、`future-plan` 设计稿、`docs` 均只有虚线等值线）。曾一度改用用户提供的参考图配色（淡粉紫→深暖色），经实际观感比对后决定保留 A 组的红→黄→绿。
11. **Tc 字段标签中英混杂**：`Tc 字段` 下拉的五个选项为中文（实验 Tc、各向异性 Eliashberg Tc…），与图表坐标轴、专业术语的英文语境不一致。
12. **年份图无温度分区**：Tc-Year 图只有空白坐标系与两条参考线，无法直观看出 Tc 高低区间。

**B 组目标**：让两图在任何选择状态下都保持对齐；固定并收窄家族控件宽度；移除社区页的组合选择器；确定品质因子填充配色；Tc 字段改英文；为年份图增加温度渐变背景。

## 用户场景与验收

### 用户故事 1：已审核数据出现在社区图表上（P0，已实现）

**独立验收**：Hg 文献在两张图上各渲染一个散点，家族标注为「单质超导体」。

**验收场景**：

1. **假如** 有一篇 approved 论文且其 `tc_results` 属于已批准版本，**当** 请求 `/api/papers/stats/tc-pressure?tc_field=experimental_tc`，**那么** 返回该数据点，含 `family_id`、`family_name`、`type`、`paper_id`。
2. **假如** 某 Tc 条目只登记了区间（`tc_min_k`/`tc_max_k`）而无单值，**当** 生成图表数据，**那么** 按区间中点上图，而不是被丢弃。
3. **假如** 论文审核通过后又被编辑出新版本，**当** 请求图表数据，**那么** 只返回已批准版本的数据，避免图上点与点击后的详情数值不一致。
4. **假如** 数据库查询失败（表缺失、列改名等），**当** 请求图表数据，**那么** 返回 HTTP 503 且不写缓存，而不是返回空数组。

### 用户故事 2：没有数据点时也显示带品质因子分区的背景（P0，已实现）

**独立验收**：任一 Tc 字段下无数据时，坐标系、品质因子色带、等值线、参考线全部照常显示，仅在图内提示无数据点。

**验收场景**：

1. **假如** 当前 Tc 字段无任何可公开数据，**当** 打开社区页，**那么** 两张图都渲染出 X/Y 坐标轴，而不是被 Alert 取代。
2. **假如** 压力图可见，**当** 渲染完成，**那么** 相邻 S 等值线之间填充色带，形成 6 个区间：`<0.2`、`0.2–0.5`、`0.5–1`、`1–2`、`2–3`、`>3`，并显示 `S=0.2`…`S=3` 标注。
3. **假如** 空数据，**当** 渲染压力图，**那么** 坐标域固定为 0–400 GPa × 0–500 K，保证色带铺满绘图区；年份图固定为 1900–次年。

> A 组实现时纵轴为 0–300 K；B 组的 FR-016 将两图纵轴统一为 0–500 K，本场景已按 B 组结论更新。
4. **假如** 任一图可见，**当** 渲染完成，**那么** 显示 77 K 与 300 K 参考线。
5. **假如** 查看 Tc-Year 图，**当** 渲染完成，**那么** 不绘制品质因子分区（S 依赖压强，年份轴上无物理意义）。

### 用户故事 3：按材料家族筛选并组合多种超导体（P0，已实现）

**独立验收**：图例与多选下拉都跟随 `material_families` 目录，默认全选，可把多个家族组合显示在一张图里。

**验收场景**：

1. **假如** 目录含 7 个内置家族与用户自建的「单质超导体」，**当** 打开社区页，**那么** 图例与下拉都列出全部 8 项，外加未分类兜底档位「其他」。
2. **假如** 未做任何选择，**当** 查看下拉，**那么** 显示「全部」且所有选项处于选中态。
3. **假如** 取消其中一个家族，**当** 查看图表，**那么** 该家族的点消失，其余家族仍同时显示在同一张图里。
4. **假如** 点击图例中的家族，**当** 状态更新，**那么** 多选下拉同步反映该变化（两者共享同一份状态）。
5. **假如** 已登录用户选过家族子集，**当** 之后新增了一个材料家族，**那么** 该新家族默认可见（选择全选时存 `null` 而非具体 id 列表）。
6. **假如** 点击「恢复默认」，**当** 状态复位，**那么** Tc 字段与家族选择一并回到默认值。

### 用户故事 4：两张图在任何选择状态下保持对齐（P1，已实现）

研究者并排比较两张图时，需要两图的坐标系处于同一水平线，才能直接对比 Tc 高度；控件的选择内容不应影响图表位置。

**优先级理由**：这是当前最影响读图的缺陷 —— 一旦左图多选几个家族，两图就错位，比对失去意义。

**独立验收**：在左图任意增减选中家族的情况下，两张图的绘图区顶边、底边始终等高。

**验收场景**：

1. **假如** 左图选中 6 个家族而右图保持「全部」，**当** 查看页面，**那么** 两图的控件区高度相同，绘图区顶边对齐。
2. **假如** 左图只选 1 个家族，**当** 查看页面，**那么** 两图仍然对齐，控件区不因文本变短而收缩。
3. **假如** 图例项数因家族可见性变化而改变，**当** 查看页面，**那么** 两张卡片的图例区高度固定，卡片底边仍对齐。
4. **假如** 两张图纵轴表示同一物理量 Tc，**当** 查看页面，**那么** 纵轴范围与刻度一致，可直接比对高度。

### 用户故事 5：控件宽度稳定且不占用过多横向空间（P2，已实现）

**独立验收**：家族选择框宽度为固定值，与选中项数量无关，两张图一致，且明显窄于选满时的文本长度。

**验收场景**：

1. **假如** 选中 6 个家族，**当** 查看选择框，**那么** 宽度与只选 1 个家族时相同。
2. **假如** 选中项名称总长超出控件宽度，**当** 查看选择框，**那么** 显示折叠摘要（如「已选 3 项」）而不是撑开控件或换行。
3. **假如** 全部选中，**当** 查看选择框，**那么** 显示「全部」。
4. **假如** 一个都未选，**当** 查看选择框，**那么** 显示「未选择」。

### 用户故事 6：图表背景直观表达 Tc 高低（P2，已实现）

**独立验收**：压力图按品质因子分区着色，年份图按温度着色，两图各有说明其色彩含义的图例。

**验收场景**：

1. **假如** 查看压力图，**当** 渲染完成，**那么** 高品质因子区为暖色、低品质因子区为冷色，并有 S 区间图例说明。
2. **假如** 查看年份图，**当** 渲染完成，**那么** 低温区为蓝色、高温区为红色，并有温度图例说明。
3. **假如** 查看任一图的纵轴，**当** 渲染完成，**那么** 范围为 0–500 K。
4. **假如** 打开 `Tc 字段` 下拉，**当** 查看选项，**那么** 五个选项均为英文，且「当前纵轴」提示同为英文。
5. **假如** 查看 `/share` 页，**当** 渲染完成，**那么** 不存在「组合」选择器及其编辑/复制/导出/新建按钮。

### 边界与异常场景

- 材料家族目录为空或加载失败时，控件仍以固定宽度渲染，仅含「其他」档位，两图仍对齐。
- 纵轴扩到 0–500 K 后，压力图的品质因子等值线被压缩到下半部分；这是为满足两图对齐而接受的取舍。
- 压力图暖色代表高品质因子（好），年份图红色代表高温（好），两图暖色语义一致，不产生冲突。

## 功能需求

- **FR-001**：图表查询必须建立在 `tc_results` → `material_states` → `superconductors` → `papers` 的 JOIN 链上，左连 `material_families` 取家族。
- **FR-002**：只公开 `papers.review_status = 'approved'` 且 `tc_results.paper_revision = papers.content_revision` 的数据。
- **FR-003**：对外 `tc_field` 白名单与默认值保持不变（前端偏好无需迁移），但映射目标从「列名」改为 `tc_results.tc_method` 的行过滤值。
- **FR-004**：Tc 取值为 `COALESCE(tc_value_k, (tc_min_k + tc_max_k) / 2)`。
- **FR-005**：实验/计算判定来自 `tc_results.result_kind`；`experimental` 为实验，其余按计算处理。
- **FR-006**：查询错误必须返回 HTTP 503 且不缓存失败结果。
- **FR-007**：分类维度为材料家族；`material_family_id` 为空归入 `family_id = 0` 的「其他」。
- **FR-008**：图例形状与颜色按目录顺序确定性分配，新增家族追加在末尾，不改变既有家族外观。
- **FR-009**：视觉编码分两通道——家族定形状与描边色，实验/计算定实心/空心；不依赖颜色单一通道。
- **FR-010**：品质因子公式沿用 `S = Tc / sqrt(39² + P²)`，档位 `[0.2, 0.5, 1, 2, 3]`；在相邻等值线之间填充色带。
- **FR-011**：空数据时仍渲染坐标系与背景，图内提示无数据点。
- **FR-012**：每张图一个家族多选控件，默认全选，与图例双向同步。
- **FR-013**：偏好版本提升到 v2 并纳入家族选择；全选存 `null`。

### B 组功能需求

- **FR-014**：两张图的控件区必须高度固定，不随家族选择内容、选中项数量或文本长度变化。
- **FR-015**：两张图的图例区必须高度固定，不随可见家族数量变化。
- **FR-016**：两张图纵轴范围必须一致，均为 0–500 K。
- **FR-017**：材料家族选择框必须为固定宽度，两图一致；宽度不得超过 200 px。
- **FR-018**：选中项文本超出控件宽度时，必须显示折叠摘要（`已选 N 项`），不得换行或撑开控件；全选显示「全部」，空选显示「未选择」。
- **FR-019**：`/share` 页不得包含 chart group 选择器及其编辑、复制、导出、新建入口。
- **FR-020**：移除组合选择器后，图表不再区分「组合内点」与「背景点」，所有数据点使用统一的前景样式。
- **FR-021**：品质因子填充必须为高 S 暖色、低 S 冷色的连续色阶，保持档位 `[0.2, 0.5, 1, 2, 3]` 与 6 个区间不变。
- **FR-022**：品质因子等值线保持绿色虚线，`S=n` 标注沿曲线放置；77 K / 300 K 参考线为深红点划线。
- **FR-023**：Tc-Year 图必须按纵轴温度填充背景，低温蓝、高温红。
- **FR-024**：两图必须各自提供说明其背景色含义的图例；压力图为 S 区间图例，年份图为温度图例。
- **FR-025**：`TC_FIELD_LABELS` 的五个标签与「当前纵轴」提示必须为英文。

## 成功标准

- **SC-001**：在家族选中项数量为 1、3、6、9 的四种状态下，两张图绘图区顶边纵坐标偏差为 0。
- **SC-002**：家族选择框在上述四种状态下宽度完全相同，且不超过 200 px。
- **SC-003**：`/share` 页源码与渲染结果中均不存在组合选择器。
- **SC-004**：两图纵轴上界均为 500 K。
- **SC-005**：`Tc 字段` 下拉的五个选项不含中日韩字符。
- **SC-006**：压力图与年份图各渲染出不少于 6 个背景填充区块，且各有一组背景色图例。

## 假设与依赖

- 品质因子填充最终采用红→黄→绿色阶（越高越暖），与年份图温度渐变的冷暖语义一致。
- 组合（chart group）功能本身保留：`/api/chart-groups` 接口与 `AdminPage` 的 `ChartGroupEditor` 入口不动，仅移除社区页 UI 入口。
- 纵轴 0–500 K 为用户明确指定，压力图一并调整以满足对齐要求。

## 范围外事项

- 不新增或修改数据库表结构与字段。
- 不改动对外 `tc_field` API 白名单、默认值与错误码。
- 不重做组合（chart group）的后端契约与管理端编辑器。
- 不补齐 `show_in_chart` 策展能力（见「边界与已知缺口」）。

## 关键决策

### D1：分类维度选材料家族，而非超导机制

`material_states` 上有两个候选字段。`superconductor_kind` 只有 `conventional`/`unconventional`/`unknown` 三档，粒度太粗，无法区分氢化物与铜氧化物。`material_family_id` 指向可扩展目录，最接近旧的 7 类硬编码，且能覆盖用户自建家族。选后者。

`state_kind` 不是分类维度：它是 `theoretical`/`experimental`/`mixed`/`unknown`，描述数据来源性质。`ChartGroupEditor` 此前误用了它。

### D2：色带用 `Customized` 画多边形，而非 `ReferenceArea`

`ReferenceArea` 只能画轴对齐矩形，无法贴合 `Tc = S×sqrt(39²+P²)` 这条曲线。改用 `Customized` 拿到 recharts 内部比例尺，在数据空间采样 64 点画多边形，边界按显示域裁剪。

### D3：家族列必须直接声明在 row 结构体上

GORM 的 `Raw().Scan()` 按原始列名匹配，**不会填充匿名嵌入结构体的字段**。初版把家族两列放进嵌入的 `chartFamilyRow`，结果家族恒为 NULL，所有点都归到「其他」。已加测试固化该约束。

### D4：偏好键名提版本而非写迁移代码

键名含 `v2`，v1 旧值根本读不到，自然回落默认值。比写迁移逻辑更简单，且旧键留在 localStorage 里无害。

### D5：不新增数据库列

组合点的家族 id 沿用既有 `custom_type` 列（存字符串形式的 id），不为此加表结构。

### D6：两图背景统一「暖 = 高、冷 = 低」

用户提供的参考图中蓝色位于左上（低压高 Tc），即**高** S 区；而年份图按 B6 要求蓝色代表**低**温。两图并排时同一颜色语义相反，容易误读。

因此确定两图统一为「暖 = 高、冷 = 低」。品质因子填充曾按参考图质感试用淡粉紫→深暖色，经实际观感比对后回退到 A 组的红→黄→绿（`#eef2f6` → `#ffb0a3`），冷暖方向不变。

### D7：对齐靠固定高度，而非内容自适应

两图错位的根因是控件文本长度影响布局高度。对齐可以靠「同步两图内容长度」或「固定容器高度」实现；前者要求两图选择状态始终一致，与「两图独立选择」的既有设计冲突。因此选择固定控件区与图例区高度，让内容变化被容器吸收。

配套要求 FR-017、FR-018：控件宽度固定 + 超长折叠，避免文本换行在固定高度容器内被裁切。

### D8：年份图渐变用 SVG linearGradient，压力图仍用多边形

年份图的温度分区边界是水平线（只依赖 Tc），可用单个矩形配 `linearGradient` 沿 Y 轴渐变，无需逐段采样。压力图的边界是 `Tc = S×sqrt(39²+P²)` 曲线，仍须用 `Customized` 多边形逐段拟合（见 D2）。

两者共用同一个 `Customized` 挂载点与比例尺读取方式，但填充几何不同。

## 边界与已知缺口

- **`show_in_chart` 策展开关消失**：该列随 `superconductor_records` 一并删除，条件化模型无替代列，策展人目前无法单独隐藏某条已审核数据。这是既成的迁移后果，本次按现状实现，未新增列。
- **三种 Tc 方法不上图**：`tc_method` 的 CHECK 约束允许 `scdft`、`other`、`unknown`，但这三种没有对应的对外 `tc_field`，相应条目不会出现在图表中。
- **图表缓存是永久缓存**：改动查询逻辑后需手动清 `chart:*` 才能看到新结果。本次验证时即因旧缓存先看到空数组。
- **纵轴扩到 500 K 压缩了压力图等值线**：`S=0.2` 等低档位曲线集中在图的下部，分辨率下降。这是为满足两图对齐（FR-016）主动接受的取舍。
