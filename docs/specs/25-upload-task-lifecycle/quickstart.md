# 验收指南：#25

1. 登录后创建任务并刷新、退出再登录，确认列表由服务端恢复。
2. 创建至 100 个活动任务，第 101 个应返回稳定的上限错误。
3. 打开 `ready` 详情，确认 `cleanup_at` 延后；仅轮询则不变化。
4. 让失败任务停留，确认查看不延长固定 24 小时。
5. 取消运行任务，确认先进入 `cancelling`，最终进入 `cancelled`。
6. 批量清理时确认运行任务被跳过。
7. 删除 Redis 状态但保留 MySQL `upload_task_id`，执行清理后正式文件仍存在。
