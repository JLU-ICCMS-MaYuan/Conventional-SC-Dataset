# 技术研究：论文分类证据作用域与汇总前状态

## 决策 1：分类证据显式标记作用域

**决策**：`paper_type_evidence` 和 `sc_type_candidates` 的每个条目增加
`scope=current_paper|referenced_work`。一个分段含两类陈述时分别输出多个证据项。

**理由**：论文引言天然同时包含本文贡献和引用背景，仅按候选值或关键词无法区分证据主体。

**备选方案**：

- 只依赖全文汇总 LLM 自行纠错：无法阻止临时表单误报，也把关键业务边界留给模型猜测，拒绝。
- 按章节名过滤引言：PDF 提取常缺少稳定章节，且引言也可能包含本文贡献，拒绝。
- 按引用标号正则过滤：无法覆盖无显式标号的背景叙述和同句混合语义，拒绝。

**证据**：生产任务 `9ba7e6d5e33040f192a604759d3d3716` 中，“Subsequent experimental work”
和“There have been few studies”分别被输出为 `experimental` 和 `review`，但均为引用背景。

## 决策 2：作用域由契约和聚合器双重约束

**决策**：分段提示词负责生成作用域；解析预览和全文汇总输入在代码边界只接受
`scope=current_paper` 的分类候选。引用证据仍保留在原始分段结果和公开证据页签。

**理由**：提示词可降低错误率，但不能作为唯一业务校验；聚合器必须执行确定性边界。

**备选方案**：仅修改提示词，不改聚合器。模型仍可能返回缺失或错误作用域，不能形成稳定回归信号，拒绝。

## 决策 3：`unknown` 是缺失判断，不是冲突类别

**决策**：本文论文类型候选聚合时忽略 `unknown`；若没有其他有效本文候选，则分类字段保持
“候选尚未汇总”，正文提示当前分段尚无法判断。

**理由**：标题或背景分段无法独立判断全文类型是正常情况，不能据此否定方法段的有效判断。

**备选方案**：继续并列展示 `unknown`，仅改变颜色。仍会让用户误以为存在语义冲突，拒绝。

## 决策 4：自由材料类型不归一化

**决策**：`sc_type_candidates.value` 继续接受自由文本；本 Bug 只按作用域筛选，不做枚举校验、
同义词合并或自动替换。数据库已有分类由编辑界面继续提供给人参考。

**理由**：#23 已确认固定枚举会阻塞新材料体系，自动永久加入或静默合并也会污染分类。

**备选方案**：强制输出 `hydride|cuprate|...`。违反现有产品决策，拒绝。

## 决策 5：分类字段使用独立的汇总前状态

**决策**：解析详情 DTO 为分类字段增加 `pending_summary` 状态，前端显示“候选尚未汇总”。
非分类单值字段继续使用 `waiting|filled|conflict`。

**理由**：同一字段的分段候选差异对标题意味着真实不一致，对论文分类却是待全文判断的正常输入，
不能共用同一语义。

**备选方案**：把所有冲突统一改名为“候选差异”。这会弱化标题、DOI 等真实风险提醒，拒绝。

## 决策 6：版本化临时分段结果并有界重读

**决策**：新分段结果写入明确的契约版本。缓存版本缺失或旧于当前版本时，Worker 在恢复处理时
重新读取该分段并覆盖旧临时结果；公开预览在重读前安全忽略无作用域分类项，但仍可显示原始分段结果。

**理由**：把旧无作用域数据默认为本文会复现错误；永久维护启发式兼容会污染主路径。上传任务最多
保留 24 小时，因此版本化重读是有界兼容。

**备选方案**：

- 缺少作用域默认 `current_paper`：会把已知错误直接带入新逻辑，拒绝。
- 永久解析旧句子猜测作用域：增加第二套分类器和长期复杂度，拒绝。
- 让旧任务全部失败：不必要地破坏可恢复上传体验，拒绝。

## 决策 7：固定产物回放而非实时 LLM 测试

**决策**：回归测试保存最小化的 Li–Mg–H 分段结构化结果，通过公开解析详情和全文汇总输入边界
重放；前端使用相同 DTO 验证标签和候选展示。

**理由**：真实 LLM 响应非确定、慢且有外部成本，不能作为提交门；固定产物仍覆盖本次故障发生的
磁盘分段结果 → 聚合 DTO → UI 调用链。

**备选方案**：只断言提示词包含某些文字。静态文本不能证明聚合和展示行为，拒绝。
