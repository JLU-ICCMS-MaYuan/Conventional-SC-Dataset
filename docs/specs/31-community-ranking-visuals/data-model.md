# 数据模型：唯一公开用户名与更名审计

## 用户 `users`

### 新增字段

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| `username` | `VARCHAR(32)` ASCII binary | 非空、唯一 | 唯一公开身份，区分大小写 |
| `username_change_allowed` | Boolean | 非空、默认 `false` | 是否仍可执行一次历史账号自助更名 |

### 既有字段约束

- `email`：继续作为唯一登录标识，不公开用于身份展示。
- `real_name`：注册请求可省略；缺省以空字符串兼容现有非空列，只保存在服务端，不进入客户端身份响应。

### 校验

- 用户选择值匹配 `^[A-Za-z][A-Za-z0-9_]{2,31}$`。
- `sc_` 前缀和保留名称不区分大小写禁止。
- 数据库唯一索引使用大小写敏感排序规则。

### 生命周期

```text
历史账号 -> 生成 sc_<12位随机字符> + 可自助更名
          -> 首次成功自助更名 -> 永久关闭自助更名

新账号 -> 注册选择 username -> 永久关闭自助更名

任意账号 -> 超级管理员带原因更名 -> 自助更名资格保持不变
```

## 用户名更名审计 `username_change_audit_events`

| 字段 | 类型 | 约束 | 含义 |
| --- | --- | --- | --- |
| `id` | Integer | 主键 | 事件标识 |
| `target_user_id` | Integer | 非空、外键 | 被更名账号 |
| `changed_by_user_id` | Integer | 非空、外键 | 执行更名的超级管理员 |
| `old_username` | `VARCHAR(32)` | 非空 | 更名前名称 |
| `new_username` | `VARCHAR(32)` | 非空 | 更名后名称 |
| `reason` | `VARCHAR(500)` | 非空 | 操作原因 |
| `created_at` | DateTime | 非空、服务端时间 | 操作时间 |

### 不变量

- 事件只能在超级管理员更名事务中插入。
- 不提供更新或删除接口。
- 新旧用户名、操作者、目标、原因和时间必须完整。
- 审计插入失败时目标用户名不得变化。
