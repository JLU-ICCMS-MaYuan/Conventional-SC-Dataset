# 图表展示与 Tc 预测实验

## 1. 这是什么业务

这一模块包含两类能力：

- 基于数据库内容的首页图表与统计展示
- 与数据库解耦的 Tc 预测实验模块

它们都面向“研究辅助”，但数据来源和闭环方式不同。

## 2. 首页图表与统计展示

### 2.1 页面入口
- 首页：`/`
- 前端脚本：`frontend/static/js/chart.js`

### 2.2 图表组成

#### 超导临界温度历史演变
- 以年份与 Tc 为主线
- 区分理论与实验数据
- 用超导体类型做颜色区分

#### 数据库实时 P-Tc 分布
- 读取数据库中标记为可展示的文献数据
- 展示压强与 Tc 的分布关系

#### 贡献者排行
- 统计提交文献数量排名
- 以用户真实姓名为展示维度

### 2.3 数据来源
- 图表数据接口：`/api/papers/stats/chart-data`
- 用户排行接口：`/api/papers/stats/user-ranking`
- 图表是否展示受文献 `show_in_chart` 控制

## 3. Tc 预测实验模块

### 3.1 入口
- 页面：`/tc-pre`
- 前端脚本：`frontend/static/js/tc_pre.js`
- 接口：`POST /api/tc-predict/`

### 3.2 输入
- 一个 VASP 结构文件 `CONTCAR/POSCAR`
- 一组 PDOS 文件，其中必须包含 `PDOS_H`

### 3.3 核心流程
1. 解析结构文件
2. 提取 H 子晶格
3. 统计 H-H 短键分布
4. 读取费米能附近的 PDOS 值
5. 根据经验公式计算中间特征
6. 返回预测 Tc 与若干中间量

### 3.4 输出
- `predicted_tc`
- `f2_value`
- `dos_h_ratio`
- `dos_h_atom_bond`
- `bonds_mean`
- `bonds_var`

## 4. 图表模块与预测模块的区别

### 4.1 图表模块
- 数据来源于数据库中的文献记录
- 结果受审核与图表可见标记影响
- 属于主业务展示链路的一部分

### 4.2 预测模块
- 输入来自用户即时上传文件
- 输出不落库、不审核、不进入文献列表
- 当前是独立实验功能

## 5. 当前边界

- 首页图表并不是通用 BI 平台，而是围绕超导文献字段做固定展示
- Tc 预测模块不自动生成文献记录
- 预测模块不能直接把结果推送到图表或体系页面
- 未来若要打通闭环，需要设计“预测结果入库”和“审核后发布”的独立流程
