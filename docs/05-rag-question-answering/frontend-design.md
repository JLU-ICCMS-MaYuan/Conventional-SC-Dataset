# 05 检索增强问答前端设计

## 页面定位

负责自然语言问答、结构化 KG 查询、向量检索、证据引用和 LLM 回答生成。

## 页面入口

- `/rag` 页面展示对话、流式输出、引用和证据卡片。
- 未来增加“从回答生成待审核数据”入口，并标注「有待建设」。
- 证据卡片应区分主业务记录、论文片段、KG 结果和外部来源。

## 交互原则

- 已落地能力正常展示，未落地能力统一使用「有待建设」标识。
- 页面只展示当前用户能理解和操作的内容，不把后端内部状态暴露成复杂表单。
- 表格、图表和上传控件保持现有 SC-Wiki 视觉风格，优先复用已有组件和样式。

## 状态设计

- 加载中：显示明确的状态文案。
- 空结果：说明当前没有可展示数据。
- 失败：展示可读错误，不吞掉后端错误原因。
- 未登录：提示登录后再使用上传、自定义或管理能力。

## 验收标准

- 健康检查准确。
- 流式输出稳定。
- 引用能追溯到来源。
