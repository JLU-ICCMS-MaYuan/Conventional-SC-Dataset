# 03 超导数据检索与数据库发现API 设计

## API 定位

本模块 API 服务于「超导数据检索与数据库发现」能力，要求字段语义稳定、来源可追溯、错误信息可读。

## 当前或规划接口

- `POST /api/papers/search-by-mode`：当前主检索接口。
- `POST /api/papers/search/all`：三源合并发现。
- 未来新增记录级表格接口，返回 `formula`、`pressure_gpa`、`superconductor_type`、`source_type`、`review_status`、`doi`。

## 请求设计原则

- 请求参数使用明确字段名，避免前端自行拼接复杂业务规则。
- 涉及用户能力的接口必须校验登录状态和角色权限。
- 涉及审核、导出、批量操作的接口必须返回可验收的结果摘要。

## 响应设计原则

- 响应保留实体 ID、显示名称、来源、审核状态和错误信息。
- 面向表格或图表的接口返回前端可直接消费的扁平结构。
- 兼容旧接口时，新字段只增不破坏旧字段。

## 错误处理

- 400：请求字段缺失或格式错误。
- 401：未登录。
- 403：权限不足。
- 404：目标数据不存在。
- 409：数据冲突，需要人工确认。

## 验收标准

- 表格六列顺序正确。
- DOI 位于第六列。
- 外部来源有明确标识。
