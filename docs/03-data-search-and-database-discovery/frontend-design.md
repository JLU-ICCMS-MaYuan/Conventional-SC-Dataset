# 03 超导数据检索与数据库发现前端设计

## 页面定位

负责元素周期表、化学式、本地数据库和外部数据库的统一发现。

## 页面入口

- `/elements` 负责元素选择，`/compound/{element_symbols}` 负责结果展示。
- 结果页改为记录级表格，固定列为体系名称、压强、超导类型、数据来源、审核状态、DOI。
- DOI 从原第三列调整到第六列，第三列只展示超导类型。

## 交互原则

- 已落地能力正常展示，未落地能力统一使用「有待建设」标识。
- 页面只展示当前用户能理解和操作的内容，不把后端内部状态暴露成复杂表单。
- 表格、图表和上传控件保持现有 SC-Wiki 视觉风格，优先复用已有组件和样式。

## 状态设计

- 加载中：显示明确的状态文案。
- 空结果：说明当前没有可展示数据。
- 失败：展示可读错误，不吞掉后端错误原因。
- 未登录：提示登录后再使用上传、自定义或管理能力。

## 验收标准

- 表格六列顺序正确。
- DOI 位于第六列。
- 外部来源有明确标识。
