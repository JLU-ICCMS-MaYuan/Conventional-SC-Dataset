# Style Profile

## Target Style

Journal/resource paper in clear scientific English. The tone should be restrained, infrastructure-focused, and evidence-bounded. The paper should read closer to a Scientific Data, database, or software-system manuscript than to a mechanism-discovery or algorithm-performance paper.

## Preferred Rhetorical Pattern

Use a controlled funnel:

1. Field-scale need: superconductivity research needs reusable structured evidence.
2. Existing infrastructure: materials, structure, and superconductivity databases exist.
3. Remaining gap: paper-level, element-centric, physical-parameter, screenshot, and review-state curation remains operationally fragmented.
4. Present system: Conventional-SC-Dataset provides an auditable workflow.
5. Boundary: no new mechanism, no validated prediction model, no community features yet.

## Language Rules

| Use | Avoid |
|---|---|
| `auditable`, `reviewable`, `element-centric`, `physical-parameter records`, `literature curation`, `workflow`, `bounded` | `novel`, `breakthrough`, `solves superconductivity discovery`, `state-of-the-art prediction`, `community platform` |
| `supports`, `enables`, `provides`, `organizes`, `separates`, `records` | `proves`, `discovers`, `guarantees`, `fully automates` |
| `current repository snapshot`, `AI-screened database`, `main metadata database` | Ambiguous `the database contains...` when multiple files differ |

## Structural Style

The manuscript should use compact sections:

| Section | Function |
|---|---|
| Abstract | Context, gap, system, evidence, boundary. |
| Introduction | Materials/structure/superconductivity database landscape, remaining curation gap, present system. |
| Related data resources | Fair comparison and complementarity. |
| Design principles | Explain why the schema/workflow choices exist. |
| System implementation | Data model, user workflow, review workflow, import/export. |
| Current repository and data status | Traceable counts and snapshot scope. |
| Comparison with recent datasets | Position against HPCSD, HTSC-2025, 3DSC, SuperCon. |
| Limitations and next steps | Boundary and roadmap. |
