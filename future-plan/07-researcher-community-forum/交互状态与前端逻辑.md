# 07 研究者社区与图表论坛：交互状态与前端逻辑

## React/Vite 落地边界

本文描述图表社区的 React 状态、个人配置、搜索、导出、数据点交互和 Material 反馈。不定义数据库写入细节。

## 核心状态

- `chartType`：`tcYear` 或 `tcPressure`。
- `publicChartData`：默认公共图表数据。
- `personalChartConfig`：当前用户个人隐藏、添加和 Tc 类型选择。
- `chartSearchFilters`：每张图自己的搜索条件。
- `selectedPoint`：当前选中数据点。
- `nearbyPointList`：点击位置附近多个点时的候选列表。
- `pointDetailSheetState`：详情 Side Sheet / Bottom Sheet 状态。
- `autoSaveState`：保存中、已保存、保存失败。
- `snackbarState`：导出、保存、恢复默认等反馈。

## 用户能力

- 访客只能查看默认公共图表。
- 注册用户可隐藏当前个人图表中的数据点。
- 注册用户可从本地 `superconductor_records` 添加数据点。
- 注册用户可修改默认公共点和个人额外点的 Tc 类型。
- 注册用户可导出当前图表图片和 CSV。
- 注册用户可恢复当前图表为默认公共图表。

## 点交互

- 点击单个点：打开详情 Side Sheet。
- 点击附近多个点：先显示候选 List，再由用户选择具体记录。
- 同一 `record_id` 重复添加时，不生成重复点，只覆盖个人 Tc 类型选择。

## 自动保存

- 隐藏点、添加点、修改 Tc 类型、恢复默认后立即保存当前图表配置。
- 保存中显示 Linear Progress 或保存中 Chip。
- 保存成功显示 Snackbar“已自动保存”。
- 保存失败显示 Snackbar“自动保存失败，请稍后重试”，并提供重试动作。

## 导出规则

- 每张图只导出当前图表。
- CSV 列顺序固定：压强、年代、Formula、Tc、DOI、审核状态、Tc 类型。
- 恢复默认只影响当前图表的个人配置，不影响另一张图和公共数据。

## 验收标准

- 两张图配置互不影响。
- 隐藏、添加和 Tc 类型选择只影响个人视图。
- 导出图片和 CSV 反映当前个人视图。
- 恢复默认不会修改 `superconductor_records` 或 `show_in_chart`。

## 旧版设计资产融合边界

- 旧版贡献者排行可作为 demo mock 数据，支持切换贡献者和查看其上传记录摘要。
- 图表点点击、CSV 导出和分享链接在 demo 中用本地状态与 Snackbar 模拟。
- 不迁移旧版首页统计脚本和全局图表初始化方式。
