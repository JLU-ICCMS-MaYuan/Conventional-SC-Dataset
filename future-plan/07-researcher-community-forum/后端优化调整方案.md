# 07 研究者社区与图表论坛：后端优化调整方案

## 核心目标

后端需要在默认图表数据之上，为注册用户提供个人图表配置能力。用户自定义只影响个人视图，不修改数据库原始记录。

## 默认图表数据

默认图表继续来自 `superconductor_records`，并通过现有图表规则过滤：

- Tc-pressure 图表需要压强和 Tc。
- Tc-year 图表需要论文年份和 Tc。
- `show_in_chart` 控制记录是否进入默认图表。

## 用户自定义数据

规划增加用户图表配置：

- 用户 ID
- 图表类型
- 隐藏记录 ID 列表
- 添加记录 ID 列表
- 创建时间
- 更新时间

删除点表示从个人图表隐藏，不删除数据库记录。添加点只能选择数据库已有记录，不能绕过审核新增公开数据。

## 验收标准

- 默认图表和个人图表互不影响。
- 用户不能删除真实数据库记录。
- 添加点必须来自已存储数据。
