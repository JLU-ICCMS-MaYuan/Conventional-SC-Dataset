# 07 研究者社区与图表论坛：页面结构与内容

## React/Vite 落地边界

本文定义社区图表页面的结构、内容和字段。图表接口与个人配置保存以 API 和后端方案为准，视觉系统服从根目录 `design.md`。

## 页面承载

- 正式入口规划：首页图表区域或后续 Research Community 页面。
- 静态示例：`index.html`。
- 页面目标：让用户配置个人 Tc-year / Tc-pressure 图表视图，同时明确个人配置不影响公共默认图表。

## Material 页面骨架

1. Top App Bar：显示“超导热点/社区图表”和账户状态。
2. Navigation Rail：当前模块高亮为超导热点或研究社区。
3. Chart Tabs / Segmented Buttons：切换 Tc-year 与 Tc-pressure。
4. Chart Cards：每张图拥有独立工具栏、画布、搜索区和结果区。
5. Point Detail Side Sheet：展示当前点记录详情和可选 Tc 字段。
6. Snackbar：自动保存、导出、恢复默认等反馈。

## 页面区块

1. 顶部说明区：说明个人图表配置不改变公共数据。
2. Tc-year 图表：独立标题、工具栏、图表画布、搜索区、结果区。
3. Tc-pressure 图表：独立标题、工具栏、图表画布、搜索区、结果区。
4. 数据点详情抽屉：展示当前点记录详情和可选 Tc 字段。
5. 社区说明区：说明个人配置状态和公共图表边界。

## 图表工具

每张图表右上角固定提供：导出图片、导出 CSV、恢复默认。两张图表独立配置、独立搜索、独立导出、独立恢复默认。

## 搜索结果表格

列顺序建议为：操作、Formula、压强、年代、默认 Tc、DOI、审核状态。每条记录可以展开查看全部非空 Tc 字段。

## 数据点详情

- Formula
- 压强
- 年代
- 当前 Tc 数值
- 当前 Tc 类型
- 全部可用 Tc 字段和数值
- DOI
- 审核状态
- 数据来源或来源标签
- 备注

## 验收标准

- Tc-pressure 和 Tc-year 两张图配置互不影响。
- 访客只能查看默认公共图表。
- 注册用户可以隐藏点、添加本地记录点、修改 Tc 类型。
