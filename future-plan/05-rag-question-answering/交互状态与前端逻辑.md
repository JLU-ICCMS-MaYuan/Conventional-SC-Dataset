# 05 检索增强问答：交互状态与前端逻辑

## React/Vite 落地边界

本文描述 RAG 页面中的 React 状态、流式输出、证据联动、降级逻辑和 Material 反馈。

## 核心状态

- `sessions`：会话列表。
- `activeSessionId`：当前会话。
- `messages`：当前对话流。
- `streamState`：空闲、生成中、完成、失败。
- `evidenceList`：当前回答的证据集合。
- `candidateRecord`：AI 生成的待审核结构化记录。
- `ragAvailability`：可用、部分降级、不可用。
- `evidenceSheetState`：证据 Side Sheet / Bottom Sheet 状态。
- `snackbarState`：复制、发送失败、重试等反馈。

## 主流程

1. 用户输入问题，点击发送按钮时产生 ripple。
2. 前端发送问题并进入流式输出状态，输入区显示 Circular Progress。
3. 回答生成时同步展示引用标记。
4. 回答完成后证据面板展示证据卡片。
5. 如果生成候选结构化记录，必须标注“非公开数据，需审核”。

## 证据联动

- 点击回答中的引用标记，高亮对应证据卡片并打开证据 Side Sheet。
- 点击证据卡片，可定位到回答中的引用位置。
- 证据来源缺失时显示“来源未提供”，不伪造 DOI 或文献名。

## 降级逻辑

- RAG 服务不可用：使用 Banner 展示降级提示。
- 检索为空：AI 回答必须说明没有找到足够证据，并提供重试或修改问题入口。
- 流式输出失败：保留已生成内容，Snackbar 提示重试。

## 验收标准

- 流式输出、引用和多轮对话体验保持可用。
- 证据类型可区分。
- AI 候选记录不会被误认为已入库。
