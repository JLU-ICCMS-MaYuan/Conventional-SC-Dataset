03 接口返回结构演示

这个演示说明“摘要 + 当前页详情字段一起返回”是什么意思：后端分页返回当前页的多条记录， 每条记录里同时包含表格需要的摘要字段和右侧卡片需要的详情字段。 用户点击表格行时，前端不用再请求一次后端，直接用这一行已经带回来的详情字段渲染右侧卡片。

页面效果：点击行后右侧详情立即切换
