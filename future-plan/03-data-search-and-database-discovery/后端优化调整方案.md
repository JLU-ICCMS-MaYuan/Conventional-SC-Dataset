# 03 超导数据检索与数据库发现：后端优化调整方案

## 核心目标

后端需要支持“同一材料体系下多数据源统一展示、筛选、排序和详情读取”。用户从元素周期表或化学式入口检索材料体系后，后端返回前端结果表格使用的摘要行；用户单击或双击某一行时，再通过详情接口读取该记录完整信息。

默认结果只展示本地数据库数据，避免外部候选材料干扰主要检索结果。用户需要时，可以切换查看 Alexandria、HTSC-2025，或选择全部数据源一起查看。

这里的“展示行”不是新的业务表，也不是把多张表混成一个含糊的数据记录。它只是后端面向前端表格整理出来的统一返回格式。

## 本地数据组成

本地数据库展示行由三类本地数据共同组成：

- `superconductors`：提供体系名称、化学式、归一化化学式、元素组成和材料体系关系。
- `superconductor_records`：提供压强、Tc、超导类型、空间群、计算或实验参数、参数来源标签等具体超导记录信息。
- `papers`：提供 DOI、论文标题、年份、期刊和本地审核状态。

因此，一条本地展示行应理解为“某个材料体系在某个压强和某篇文献来源下的一条可展示超导数据”，而不是单独来自 `superconductors`、`superconductor_records`、`papers` 中任意一张表。

本地 `source_record_id` 建议使用 `superconductor_records.id`。

## 外部数据处理

Alexandria 和 HTSC-2025 只作为外部数据源接入，不直接等同于本地数据库中的已审核数据。

后端需要为外部数据建立适配层，把外部字段转换成前端表格可用的统一摘要格式：

- Alexandria 数据必须标记 `source_system = alexandria`。
- HTSC-2025 数据必须标记 `source_system = htsc2025`。
- 外部数据的审核状态不能使用本地 `papers.review_status`。
- 外部数据建议统一显示为“外部来源”或“未纳入本地审核”。
- 外部数据如果没有 DOI，应保留空值或展示来源编号，不能用无关字段冒充 DOI。
- 外部来源只返回自身能提供的字段，不强行补齐本地字段。

## 数据源筛选规则

后端检索接口需要支持数据源筛选参数，建议命名为 `source_scope`：

| 参数值 | 含义 | 返回范围 |
| --- | --- | --- |
| `local` | 默认值 | 只返回本地数据库数据 |
| `alexandria` | Alexandria 数据源 | 只返回 Alexandria 候选数据 |
| `htsc2025` | HTSC-2025 数据源 | 只返回 HTSC-2025 候选数据 |
| `all` | 全部来源 | 同时返回本地、Alexandria、HTSC-2025 数据 |

选择 `all` 时，后端仍然必须保留清晰的数据来源标签，不能把外部数据伪装成本地已审核数据。

## 代表 Tc 规则

后端需要统一计算代表 Tc，用于表格展示、筛选和排序。

默认代表 Tc 规则为按以下顺序取第一个非空值：

1. `experimental_tc`
2. `anisotropic_eliashberg_tc`
3. `isotropic_eliashberg_tc`
4. `allen_dynes_tc`
5. `mcmillan_tc`

后端返回摘要行时需要同时返回：

- `representative_tc`
- `representative_tc_field`
- `representative_tc_label`

03 检索页只展示和说明代表 Tc，不允许用户修改 Tc 类型。Tc 类型选择属于 07 图表自定义功能。

## 列表摘要字段

列表接口只返回表格和分页所需摘要字段，不返回完整详情，避免列表接口过重。

摘要字段建议包含：

| 字段 | 含义 |
| --- | --- |
| `source_system` | 来源系统，例如 `local`、`alexandria`、`htsc2025` |
| `source_record_id` | 来源系统中的记录 ID |
| `year` | 年份 |
| `formula` | 体系名称或化学式 |
| `superconductor_type` | 超导类型 |
| `pressure_gpa` | 压强，单位 GPa |
| `representative_tc` | 代表 Tc |
| `representative_tc_field` | 代表 Tc 对应后端字段 |
| `representative_tc_label` | 代表 Tc 中文或展示标签 |
| `space_group_number` | 空间群编号 |
| `data_source` | 面向用户展示的数据来源 |
| `review_status` | 审核状态；外部数据使用外部来源状态 |
| `doi` | DOI；没有 DOI 时为空 |
| `show_in_chart` | 是否进入默认图表，本地数据可用 |

## 筛选规则

后端检索需要支持以下筛选：

- Formula 模糊搜索。
- 代表 Tc 范围。
- 压强范围。
- 年份范围。
- 超导类型。
- 空间群编号：只支持 `space_group_number`，不支持空间群字符串。
- 数据来源。
- 审核状态。
- DOI / 关键词。
- 是否进入图表：`show_in_chart`。

空间群筛选只支持编号，避免字符串写法差异造成误匹配。

外部来源只执行其能支持的筛选条件。无法支持的筛选条件需要明确降级处理：要么忽略该外部来源的不可用筛选，要么在响应中标记该来源不支持对应筛选，不能伪造字段。

## 排序规则

默认排序为代表 Tc 降序。

后端需要支持：

- 代表 Tc 升序 / 降序。
- 年份升序 / 降序。
- 压强升序 / 降序。
- Formula 字母顺序。
- 审核状态。
- 数据来源。

代表 Tc 排序必须在后端完成，避免分页后前端只对当前页局部排序。

## 详情读取

详情接口使用 `source_system + source_record_id` 定位记录，支持本地和外部来源。

### 本地详情

本地详情需要返回完整字段，供右侧详情卡片和独立详情页使用：

- Formula
- 年份
- DOI
- 论文标题
- 期刊
- 审核状态
- 数据来源
- 全部 Tc 字段
- lambda
- omega_log
- N(Ef)
- s_factor
- 压强
- 空间群编号
- 空间群符号
- 晶体结构
- 晶胞参数
- 体积
- 计算软件
- 方法
- 赝势
- 交换关联泛函
- k/q 网格
- 能量截断
- 备注

### 外部详情

Alexandria 和 HTSC-2025 详情只返回该来源能提供的字段。缺失字段应返回空值或明确标记为“未提供”，不能强行补齐。

外部详情需要保留：

- `source_system`
- `source_record_id`
- 来源标签
- 外部来源说明

前端据此显示“外部来源，未纳入本地审核”。

## 独立详情页支持

后端详情接口需要同时服务：

- `/compound/:elementSymbols` 页面右侧详情卡片。
- 未来 `/records/:sourceSystem/:sourceRecordId` 独立详情页。

独立详情页不要求新增不同的数据模型，可以复用同一个详情响应，只在前端展示层扩展布局。

## 验收标准

- 默认本地结果按代表 Tc 降序返回。
- 列表接口只返回摘要字段，不返回完整详情。
- 列表摘要字段能满足 9 列表格展示。
- Formula、代表 Tc、压强、年份、超导类型、空间群编号、数据来源、审核状态、DOI / 关键词、`show_in_chart` 均可筛选。
- 空间群筛选只使用编号。
- 详情接口支持本地、Alexandria、HTSC-2025。
- 本地详情包含全部 Tc 字段、超导参数、结构信息、计算信息和论文信息。
- 外部来源字段缺失时不伪造数据。
- 现有 `POST /api/papers/search-by-mode` 和 `POST /api/papers/search/all` 暂时保留，避免破坏旧结果页。
