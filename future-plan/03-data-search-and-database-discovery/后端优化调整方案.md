# 03 超导数据检索与数据库发现：后端优化调整方案

## 核心目标

后端需要支持“同一材料体系下多数据源统一展示与筛选”。用户从元素周期表或化学式入口检索材料体系后，后端返回前端表格可以直接展示的数据行，字段语义对应：体系名称、压强、超导类型、数据来源、审核状态和 DOI。

默认结果只展示本地数据库数据，避免外部候选材料干扰主要检索结果。用户需要时，可以切换查看 Alexandria、HTSC-2025，或选择全部数据源一起查看。

这里的“展示行”不是新的业务表，也不是把多张表混成一个含糊的数据记录。它只是后端面向前端表格整理出来的统一返回格式。

## 本地数据组成

本地数据库展示行由三类本地数据共同组成：

- `superconductors`：提供体系名称、化学式、归一化化学式、元素组成和材料体系关系。
- `superconductor_records`：提供压强、Tc、超导类型、计算或实验参数、参数来源标签等具体超导记录信息。
- `papers`：提供 DOI、论文标题、年份、期刊和本地审核状态。

因此，一条本地展示行应理解为“某个材料体系在某个压强和某篇文献来源下的一条可展示超导数据”，而不是单独来自 `superconductors`、`superconductor_records`、`papers` 中任意一张表。

## 外部数据处理

Alexandria 和 HTSC-2025 只作为外部数据源接入，不直接等同于本地数据库中的已审核数据。

后端需要为外部数据建立适配层，把外部字段转换成前端表格可用的统一展示行格式：

- Alexandria 数据必须标记 `source_system = alexandria`。
- HTSC-2025 数据必须标记 `source_system = htsc2025`。
- 外部数据的审核状态不能使用本地 `papers.review_status`。
- 外部数据建议统一显示为“外部来源”或“未纳入本地审核”。
- 外部数据如果没有 DOI，应保留空值或展示来源编号，不能用无关字段冒充 DOI。

## 数据源筛选规则

后端检索接口需要支持数据源筛选参数，建议命名为 `source_scope`：

| 参数值 | 含义 | 返回范围 |
| --- | --- | --- |
| `local` | 默认值 | 只返回本地数据库数据 |
| `alexandria` | Alexandria 数据源 | 只返回 Alexandria 候选数据 |
| `htsc2025` | HTSC-2025 数据源 | 只返回 HTSC-2025 候选数据 |
| `all` | 全部来源 | 同时返回本地、Alexandria、HTSC-2025 数据 |

选择 `all` 时，后端仍然必须保留清晰的数据来源标签，不能把外部数据伪装成本地已审核数据。

## 统一展示行字段

后端返回给前端的每一行建议包含以下字段：

| 字段 | 含义 |
| --- | --- |
| `formula` | 体系名称或化学式 |
| `pressure_gpa` | 压强，单位 GPa |
| `superconductor_type` | 超导类型 |
| `data_source` | 面向用户展示的数据来源，例如“本地数据库”“Alexandria”“HTSC-2025” |
| `review_status` | 审核状态；本地数据使用本地审核状态，外部数据使用外部来源状态 |
| `doi` | DOI；没有 DOI 时为空 |
| `source_system` | 机器可读来源标识，例如 `local`、`alexandria`、`htsc2025` |
| `source_record_id` | 来源系统中的记录 ID，用于详情跳转或排查 |

该统一格式只服务检索结果页展示，不要求改变底层真实数据表结构。

## 检索规则

- 元素精确检索返回完全匹配元素集合的体系。
- 元素组合检索返回所选元素相关子组合。
- 元素包含检索返回包含所选元素的体系。
- 化学式检索优先返回本地数据库记录。
- 默认 `source_scope = local`，只查询本地数据库。
- 当 `source_scope` 为外部来源或 `all` 时，再调用对应外部数据适配逻辑。

## 排序与展示规则

- 默认本地数据优先按相关性、Tc、年份或现有检索排序规则展示。
- `all` 模式下建议保留来源分组或来源标签，避免用户误读。
- 同一体系下来自不同来源的数据可以同时出现，但必须通过 `source_system` 和 `data_source` 区分。
- 未审核本地数据、已审核本地数据、外部候选数据应保持状态差异，不做混合覆盖。

## 验收标准

- La-H 体系检索默认只展示本地 La-H 数据。
- La-H 体系检索能返回 LaH、LaH6、LaH4、LaH2、LaH3 等多种本地化学式条目。
- 切换 Alexandria 后，只展示 Alexandria 候选数据。
- 切换 HTSC-2025 后，只展示 HTSC-2025 数据。
- 选择全部查看时，同一张表格中展示所有来源，但来源和审核状态清晰可区分。
- 本地数据的 DOI 和审核状态来自 `papers`，外部数据不伪装成本地审核结果。
- 文档和接口说明中不再使用“记录级结果来自五个来源”这类含糊表述。
