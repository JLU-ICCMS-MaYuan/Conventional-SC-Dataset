# 03 超导数据检索与数据库发现：页面结构与内容

## React/Vite 落地边界

本文定义检索页面的 JSX 信息结构、字段和页面内容。接口返回结构以本目录 `API接口调整方案.md` 为准。

## 页面承载

- 正式入口规划：`/compound/:elementSymbols` 检索结果页；元素周期表入口仍由 `/elements` 承担。
- 静态示例：`index.html`、`compound-search-demo.html`、`api-return-demo.html`。
- 页面目标：让用户快速筛选和比较多条超导记录，并查看单条记录的完整科研细节。

## 页面区块

1. 顶部检索上下文：展示当前元素体系、检索模式和数据源范围。
2. 数据源切换：本地数据库、Alexandria、HTSC-2025、全部来源。
3. 筛选区：Formula、代表 Tc、压强、年份、超导类型、空间群编号、数据来源、审核状态、DOI / 关键词、`show_in_chart`。
4. 结果表格：默认主视图，用于比较和排序。
5. 右侧详情卡片：单击表格行后展示选中记录详情。
6. 接口说明区：说明代表 Tc 规则、外部来源和无需二次详情请求的字段策略。

## 结果表格列

表格列顺序固定为：

1. 年份
2. 体系名称
3. 超导类型
4. 压强
5. 代表 Tc
6. 空间群
7. 数据来源
8. 审核状态
9. DOI

表格只展示代表 Tc，不在一行塞入全部 Tc 字段。全部 Tc 字段放入右侧详情卡片和独立详情页。

## 代表 Tc 规则

默认代表 Tc 优先级：

1. `experimental_tc`
2. `anisotropic_eliashberg_tc`
3. `isotropic_eliashberg_tc`
4. `allen_dynes_tc`
5. `mcmillan_tc`

表格 tooltip 或小标签需要显示代表 Tc 来自哪个字段。

## 右侧详情内容

- 基础信息：Formula、年份、DOI、论文标题、期刊、审核状态、数据来源。
- 超导参数：全部 Tc 字段、lambda、omega_log、N(Ef)、s_factor。
- 结构信息：压强、空间群编号、空间群符号、晶体结构、晶胞参数、体积。
- 计算与备注：计算软件、方法、赝势、交换关联泛函、k/q 网格、能量截断、备注。

## 独立详情页规划

双击表格行规划跳转 `/records/:sourceSystem/:sourceRecordId`，例如 `/records/local/123`、`/records/alexandria/mp-xxxx`、`/records/htsc2025/456`。

## 验收标准

- 默认只展示本地数据库结果。
- 表格按固定 9 列展示。
- 默认按代表 Tc 降序排序。
- 单击表格行显示右侧详情，双击规划进入独立详情页。
- 外部来源字段缺失时不伪造数据。
