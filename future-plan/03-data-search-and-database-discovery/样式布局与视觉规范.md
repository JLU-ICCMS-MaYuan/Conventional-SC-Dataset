# 03 超导数据检索与数据库发现：样式布局与视觉规范

## React/Vite 落地边界

本文只描述检索模块的布局和样式。全局视觉规范以根目录 `design.md` 为唯一来源。

## 布局结构

- 页面采用“检索上下文 + 筛选 + 表格 + 详情”的工作台结构。
- 桌面端结果表格与右侧详情卡片并排。
- 移动端右侧详情移动到表格下方。
- `api-return-demo.html` 可采用表格/详情与 JSON 代码块双列结构。

## 视觉层级

- 结果表格是主视图，卡片只用于选中记录详情。
- 不再在表格下方保留每条记录摘要卡片列表，避免重复和拥挤。
- 数据源切换使用分段按钮或紧凑 tabs 样式。
- 外部来源需要明确标签，但不使用强烈彩色强调。

## 表格样式

- 表头固定语义，列宽优先保证 Formula、代表 Tc、DOI 可读。
- 窄屏下表格允许横向滚动，不压缩科学字段。
- 选中行使用轻边框或浅底色表达，不改变表格行高度。

## 详情卡片样式

- 详情卡片分组展示，默认展开“基础信息”和“超导参数”。
- “结构信息”和“计算与备注”默认折叠。
- 缺失字段显示“未提供”，不留下大面积空白。

## 禁止项

- 不恢复旧 HTML 中的蓝绿变量和彩色 badge。
- 不使用装饰性卡片堆砌结果列表。
- 不在本模块重新定义全局按钮、圆角和色彩。
