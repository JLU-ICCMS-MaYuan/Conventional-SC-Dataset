# 03 超导数据检索与数据库发现：样式布局与视觉规范

## React/Vite 落地边界

本文只描述检索模块的布局和样式。全局视觉规范以根目录 `design.md` 为唯一来源。

## Material 布局结构

- 页面采用“搜索 Surface + Filter Chips + Data Table + Side Sheet”的工作台结构。
- 桌面端结果表格与右侧详情并排，详情使用 Elevated Side Sheet。
- 移动端详情改为 Bottom Sheet 或详情页。
- `api-return-demo.html` 可采用 Data Table / Details / JSON Code Surface 三栏或双列结构。

## Surface 与 Elevation

- 搜索和筛选区：Elevation 1。
- 结果表格：Elevation 1，行 hover 有浅色 Surface 变化。
- 详情 Side Sheet：Elevation 3。
- 下载或导出 FAB：Elevation 4，仅在当前页面需要强主操作时出现。

## 表格样式

- 表头固定语义，列宽优先保证 Formula、代表 Tc、DOI 可读。
- 窄屏下表格允许横向滚动，不压缩科学字段。
- 选中行使用 primary container 浅底、左侧细条和 selected state。
- 数据源、审核状态、Tc 来源使用 Chips，不使用混乱彩色 badge。

## 详情样式

- 详情按 Accordion 或 Card Sections 分组展示。
- 默认展开“基础信息”和“超导参数”。
- “结构信息”和“计算与备注”默认折叠。
- 缺失字段显示“未提供”，不留下大面积空白。

## 禁止项

- 不恢复旧 HTML 中的蓝绿变量和随机彩色 badge。
- 不使用装饰性卡片堆砌结果列表。
- 不在本模块重新定义全局按钮、圆角和色彩。
