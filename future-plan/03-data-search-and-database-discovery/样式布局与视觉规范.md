# 03 超导数据检索与数据库发现：样式布局与视觉规范

## React/Vite 落地边界

本文只描述检索模块的布局和样式。全局视觉规范以根目录 `design.md` 为唯一来源。

## Material 布局结构

- 页面采用“三层状态流 + Search Surface + Filter Chips + Data Table + 详情页”的工作台结构。
- 桌面端 Data Table 与右侧 Side Sheet 并排，详情层使用主详情区 + Elevated Side Sheet。
- 移动端详情改为 Bottom Sheet 或详情页。

## Surface 与 Elevation

- 搜索和筛选区：Elevation 1。
- 结果表格：Elevation 1，行 hover 有浅色 Surface 变化。
- 详情 Side Sheet：Elevation 3。
- 下载或导出 FAB：Elevation 4，仅在当前页面需要强主操作时出现。

## 表格样式

- 表头固定语义，列宽优先保证 Formula、代表 Tc、DOI 可读。
- 窄屏下表格允许横向滚动，不压缩科学字段。
- 选中行使用 primary container 浅底、左侧细条和 selected state。
- 数据源、审核状态、Tc 来源使用 Chips，不使用混乱彩色 badge。

## 三层 demo 布局

- 第一层使用“轻量 Search Surface + 周期表工作台”结构，完整周期表在桌面端铺开，移动端允许横向滚动。
- 第一层元素筛选操作区使用单行工具条：Segmented Buttons 在前，`进入页面` 和 `清除选择` 在后；按钮不放入 Page Header 右侧。
- 第二层使用“左侧筛选栏 280px + 中间 Data Table + 右侧 360px Side Sheet”的工作区比例，结果主视图必须是固定 9 列表格。
- 第三层使用“主详情区 + 右侧结构预览 Side Sheet”，结构预览只做 mock，不引入真实 3D 渲染。
- 三层共用 Top App Bar 和 Navigation Rail，但不在顶部显示 `元素搜索 / 结果表格 / 详情页面` 三段式层级切换 pill；层级切换只通过页面内返回按钮、进入页面按钮和表格双击行为完成。

## 周期表类别配色

周期表属于领域视图，允许继承旧版元素类别配色；这是本模块对全局 Material 色彩规则的局部例外，不扩散为全站按钮、卡片或导航颜色。

| 类别 | 颜色 |
| --- | --- |
| alkali-metal | `#f4bcc2` |
| alkaline-earth | `#e3bd91` |
| transition-metal | `#edcda9` |
| post-transition | `#ededab` |
| metalloid | `#9cd5a8` |
| nonmetal | `#a3d7dc` |
| halogen | `#b7a0db` |
| noble-gas | `#cfb5d6` |
| lanthanide | `#cea1ce` |
| actinide | `#c782ab` |

- 元素格子显示原子序号和英文元素符号，不显示中文元素名。
- 主表中的镧系/锕系入口格显示 `La` 和 `Ac`，不显示 `La-Lu` 或 `Ac-Lr`，避免文字超出方框。
- 选中态使用加粗边框、轻遮罩或浅色描边表达，不能用纯色覆盖元素类别底色。
- hover 可保留轻微上浮和阴影，但不能破坏类别色的可识别性。

## 第二层筛选栏样式

- 筛选栏使用单张 Material Card，不拆成多个堆叠卡片。
- 筛选项全部平铺在同一张筛选卡片内，不再拆分“基础筛选 / 高级筛选”标题。
- 数据来源使用 Chip / Segmented Button；Formula、代表 Tc、压强、年份使用输入；超导类型、空间群号范围、审核状态使用数据库备选项；布尔筛选 `show_in_chart` 使用开关或二态 Chip。
- 空间群范围使用两个紧凑备选控件表达最小编号和最大编号，避免用户手填非法空间群字符串。
- 控件垂直间距使用 8px 系统，字段 label 必须短而清晰，避免卡片过宽。

## 详情样式

- 详情按 Accordion 或 Card Sections 分组展示。
- 第二层右侧 Side Sheet 默认隐藏；用户单击 Data Table 行后才以 Elevated Surface 形式出现，避免页面初始状态右侧出现未主动选择的详情卡片。
- 默认展开“基础信息”和“超导参数”。
- “结构信息”和“计算与备注”默认折叠。
- 缺失字段显示“未提供”，不留下大面积空白。

## 禁止项

- 不恢复旧 HTML 中的蓝绿变量和随机彩色 badge。
- 不使用装饰性卡片堆砌结果列表。
- 不在本模块重新定义全局按钮、圆角和色彩。

## 旧版设计资产融合边界

- 周期表、图表、3D 结构属于领域视图，可以自定义渲染；外层仍使用 Material Surface、Segmented Buttons、Filter Chips、Data Table 和 Side Sheet。
- 周期表格子的类别色沿用旧版色彩，外层容器和控制区仍使用 Material Surface、Segmented Buttons 和 Buttons。
- 旧版结果卡片可转译为“表格主视图 + 右侧详情”，避免重新堆叠大量文献卡片。
- 下载与上传分区保持分离：下载属于检索/分享 Surface，上传属于分享/录入 Surface。
