# 04 超导发展知识图谱：样式布局与视觉规范

## React/Vite 落地边界

本文只描述图谱页面的布局与视觉约束。全局视觉风格服从根目录 `design.md`。

## Material 布局结构

- 桌面端使用 Graph Canvas Surface + 右侧 Side Sheet。
- 图谱画布占据主要空间，详情面板保持窄而可读。
- 移动端先展示图谱摘要和节点列表，再通过 Bottom Sheet 展示详情。
- 关系说明区放在图谱下方，不干扰画布探索。

## 图谱视觉

- 节点和边可以使用主色、辅色和中性色，但数量克制。
- 里程碑论文节点可用更高 elevation、较大节点和 primary 色表达权重。
- 关系边需要有方向和短标签。
- 局部图谱状态用 Chips 表达，不把数据来源画成彩色噪声。

## Surface 与组件

- 图谱画布使用 Surface container + Elevation 1。
- 工具栏使用 Icon Buttons、Filter Chips 和 Segmented Buttons。
- 详情面板使用 Side Sheet，Elevation 3。
- 节点详情中的 DOI、年份、期刊使用 List Item 或 Key Value Rows。

## 禁止项

- 不把参数属性画成默认图谱节点。
- 不把数据来源画成节点。
- 不使用彩虹网络图作为主视觉。
